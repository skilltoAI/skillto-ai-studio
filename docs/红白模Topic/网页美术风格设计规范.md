# 网页美术风格设计规范

交付对象为 skillto.ai 的设计和前端团队。适用页面为官方免费和付费红白模 Topic，包括 STASS 内嵌版与独立网页。沿用 skillto.ai 自身品牌和组件。

## 1. 视觉方向

用白底、浅灰分隔和深色文字承载红白模动作视频。封面与正片提供主要色彩，播放控制和提示词操作保持低干扰。付费状态用一个带文字的「付费专题」标签表达。价格和购买按钮放在同一个操作区，页面主体保留与免费专题相同的排版。

| 项目 | 表现 |
|---|---|
| 页面背景与卡片 | 白底 `#FFFFFF`，次级区域 `#F7F8FA`，分隔 `#E5E7EB`。卡片圆角 10–12 px，封面圆角 8 px。 |
| 文字与主操作 | 主文字 `#17191C`，辅助 `#5E636B`，按钮优先用官网品牌主色及现有状态。品牌色尚未提供时使用深色主按钮 `#17191C` 配白字。 |
| 字体 | 优先复用官网字体。回退采用系统无衬线与中文系统字体。专题标题 18 px，卡片标题 16 px，提示词预览 12 px，保留工作台的提示词滚动预览和展开交互。 |
| 布局 | 内容区最大宽度 1400 px。横向边距桌面 28 px、窄屏 16 px。栅格内容宽度 560 px 及以下用单列，561–900 px 用两列，901 px 起用三列。嵌入版以 iframe 的可用宽度计算。 |
| 封面和视频 | 封面保持 16:9。使用发布者批准的封面或视频画面；播放区用 `object-fit: contain` 保留完整动作和身体边界。无封面时用浅灰占位。只加载可见卡片附近的媒体元数据，点击播放，默认不自动播放。 |

## 2. 页面状态

**免费页面**从专题名称和简介进入卡片列表。卡片顺序为标题和复制图标、16:9 媒体区、描述、提示词预览与来源入口。长提示词在卡片中默认显示一段，可展开全文，复制动作始终复制完整原文。按钮使用「播放」「复制提示词」等动作文字或同义可访问标签。来源开放时显示「查看飞书来源」。访客可直接浏览和播放。

**付费页面**使用同一页头和栅格。未购买时卡片排版与免费版一致，页头左上显示实际价格、适用的原价或优惠及购买入口。每张卡片展示静态视频截图及最多 50 个字符的提示词，末尾标记「付费解锁」。完整提示词及视频来源由已解锁会话获取。购买后用同款卡片展示完整提示词、站内播放器和下载入口。每张锁定封面也显示播放图标，点击进入购买流程。未登录点击购买打开统一登录，返回后显示商品摘要和应付金额。嵌入版的购买操作由 STASS 显示可点击的顶层跳转，支付在顶层页面完成。

**独立网页和嵌入页**共用专题组件。独立网页使用官网页头和品牌导航。嵌入页从专题标题开始，省去全站页头、全站侧栏和页脚，STASS 的 Topic 侧栏与顶部导航仍可用。已下架展示明确状态，载入失败提供重试，视频失败提供单卡反馈。空专题使用自然留白和简短说明。

正文、按钮和状态对比度按 WCAG AA 校验。提供可见键盘焦点、真实状态文本、可读的封面替代文字与可聚焦的视频控件。验收 360 px 的嵌入宽度、200% 缩放和键盘进入与离开 iframe。 [WCAG 2.2](https://www.w3.org/TR/WCAG22/)

## 3. iframe 交付要求

```html
<iframe
  title="红白模专题 · Skillto.ai"
  src="https://www.skillto.ai/red-white/embed/topics/sto_nov_demo"
  sandbox="allow-scripts allow-same-origin allow-downloads allow-popups allow-popups-to-escape-sandbox"
  referrerpolicy="no-referrer"
  allow="fullscreen">
</iframe>
```

- 免费和付费共用同一嵌入协议。页面打开后立即显示真实内容或锁定宣传页。避免第三方 Cookie 同意墙、帐号弹窗和全页登录跳转。STASS 主区保留「在浏览器打开」，加载超时后展示重试，建议阈值为 12 秒。切换 Topic 时销毁旧 iframe，停止播放并移除监听。
- STASS 对嵌入域与独立页域分别检查完整 HTTPS Origin、固定路由与 Topic ID，在工作台响应的 `frame-src` 中加入正式嵌入域。skillto.ai 在嵌入路由响应中配置 `frame-ancestors http://127.0.0.1:8080` 和实际获准的其他宿主 Origin。站点对独立页保留自身防嵌入策略。端口、LAN 和 HTTPS 部署按实际配置，禁止将来路参数写进允许名单。 [CSP Level 3](https://www.w3.org/TR/CSP3/#directive-frame-ancestors) · [HTML iframe 标准](https://html.spec.whatwg.org/multipage/iframe-embed-object.html)
- 父页向 iframe 发送 `skillto.redWhite.init`，包含 `version: 1`、`topicId`、本次随机 `mountId`。iframe 在免费内容或付费锁定页就绪后回 `skillto.redWhite.ready`，回显三字段和 `status: "public" | "locked" | "unlocked"`。购买或恢复权益用 `skillto.redWhite.openOnline` 提示外壳显示用户点击的顶层按钮，可附有严格格式的公开挑战 ID。失败用 `skillto.redWhite.error` 返回受控错误码。
- 消息双方检查精确 Origin、`event.source`、Topic、挂载 ID 和协议版本。使用精确 `targetOrigin`。父页只按既有 `externalUrl` 和固定线上入口构造跳转，拒绝任意 URL。消息只同步展示和操作入口。 [WHATWG 跨文档消息规范](https://html.spec.whatwg.org/multipage/web-messaging.html#crossDocumentMessages)

## 4. 给设计与前端的验收画面

- 桌面免费专题首屏。左侧为 STASS 官方与本机目录，右侧立即出现 skillto.ai 的标题、内容和播放入口。
- 桌面付费专题首屏。无登录态也能看到正规专题页、实际价格和购买入口。完成访客购买后能看到解锁卡片。
- 360 px 嵌入页。单列、标题可换行、控制可触达。购买打开顶层网站统一登录，返回后的权益状态清晰。
- 网络异常及嵌入失败。提供原线上地址的打开入口。切换 Topic 保持当前目录高亮，旧页面不继续播放。

嵌入专题使用通栏白底。iframe 在现有握手后发送 `skillto.redWhite.resize`，回显 `version`、`topicId`、`mountId`，并附整数像素 `height`。父页在通过现有来源校验且高度在 1–250000 px 范围内时调整 iframe，由工作台外层滚动。嵌入成功后的独立页链接放在内容下方，购买和故障时保留上方入口。
