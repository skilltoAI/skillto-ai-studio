## 接入步骤

1. 服务端请求 `GET /api/v1/red-white/topics`，按返回顺序渲染 `topics`，以 `defaultTopicId` 选中默认专题。用 `id` 作为稳定键，`revision` 作为版本。空目录时显示空状态。浏览器跨域调用依赖 CORS，生产目录当前未对第三方网页返回允许访问的响应头。
2. 请求 `GET /api/v1/red-white/topics/{id}` 获取 `embed.externalUrl`。常规 Web 项目用新标签页或顶层导航打开该 URL。若目录展示实时价格，仅对付费项读取匿名 `content` 的 `offer.amountMinor` 和 `offer.currency`。人民币金额单位为分，`900` 表示 ¥9.00。购买时以 Skillto.ai 结账报价为准。
3. 每次刷新目录时可携带上次的 `ETag` 作为 `If-None-Match`。收到 `304` 可复用前一次响应。目录中的 `cloudValidUntil` 是快照到期时间。过期后重新请求；专题下架后从目录移除，旧链接的 API 返回 `404 TOPIC_NOT_FOUND`。

```bash
curl -fsS -H 'Accept: application/json' https://www.skillto.ai/api/v1/red-white/topics
curl -fsS https://www.skillto.ai/api/v1/red-white/topics/sto_bbb5b7e0-777b-5f62-ac4d-5e9070fe0c49
curl -fsS https://www.skillto.ai/api/v1/red-white/topics/sto_bbb5b7e0-777b-5f62-ac4d-5e9070fe0c49/content
```

## 内容接口

| 请求 | 成功响应 |
| --- | --- |
| `GET /api/v1/red-white/topics` | `view=cloud`，含默认 ID、公开目录、快照 ID 和到期时间 |
| `GET /api/v1/red-white/topics/{id}` | `kind=cloud-embed`，含 `topic`、`embed.url`、`embed.externalUrl` 与 `embed.protocolVersion` |
| `GET /api/v1/red-white/topics/{id}/content` | 免费项为 `cloud-public`。付费访客未解锁时为 `cloud-locked`，含报价和 `previewItems`，`itemCount=null`。Skillto.ai 的已购会话为 `cloud-unlocked` |

付费锁定卡片只暴露 `id`、`title`、`position`、静态 `cover` 和 `promptPreview`。展示 `promptPreview` 时在末尾添加「付费解锁」。封面是视频截图，不提供视频播放或下载地址。若 `offer.listAmountMinor` 大于成交报价，可并列显示划线原价。

免费和已解锁响应的 `items[].prompt` 按纯文本渲染并保留换行。`items[].video.mode=stream`，`playbackUrl` 为 Skillto.ai 同源媒体路径。浏览器原生播放器支持分段读取。追加 `?download=1` 触发下载。付费媒体在每次请求时校验权益，第三方项目负责打开官方页面，浏览器中的播放、下载与权益均由官方页面处理。内容响应带 `private, no-store`，禁止写入共享缓存。收到 `409 TOPIC_REVISION_MISMATCH` 时，刷新描述并从第一页获取。继续分页时原样传入 `nextCursor`，遇 `null` 停止。

付费下单需要 Skillto.ai 登录。打开独立页后追加 `?buy=1` 可进入购买流程，登录完成后回到同一专题。订单与解锁权益绑定账号，退款撤销站内权益。接入方无需传递登录令牌或实现支付回调。

## 本机 STASS 嵌入

生产嵌入页当前允许的父页面 Origin 为 `http://127.0.0.1:8080`。其他项目的网页应使用独立页。需要在不同 Origin 中嵌入时，先登记精确的父页面 Origin 并完成双方联调。

本机 STASS 使用描述中的 `embed.url`，iframe 设 `sandbox="allow-scripts allow-same-origin allow-downloads allow-popups allow-popups-to-escape-sandbox"`、`allow="fullscreen; clipboard-write"` 和 `referrerpolicy="no-referrer"`。父页面只向 `https://www.skillto.ai` 发送版本为 1 的 `skillto.redWhite.init`，并携带 `topicId`、随机 `mountId`。只处理同时匹配 Origin、iframe window、协议版本、Topic ID 和挂载 ID 的 `skillto.redWhite.ready` 与 `skillto.redWhite.openOnline`。对后者，收到 `intent=purchase` 时父页面把独立页添加 `?buy=1` 作为后备购买入口。新版 iframe 可经用户点击打开独立结账页。浏览器限制第三方登录状态时，用户可在独立页查看账号权益。iframe 加载失败时保留独立页链接。

接入验收应覆盖默认免费专题、付费锁定报价、未购买时提示词最多 50 个字、只有静态封面、响应无飞书视频或下载链接、下架 404，以及 iframe 不可用时可打开独立页。订单、重复回调和退款用测试支付事件验收。

嵌入专题使用通栏白底。iframe 在现有握手后发送 `skillto.redWhite.resize`，回显 `version`、`topicId`、`mountId`，并附整数像素 `height`。父页在通过现有来源校验且高度在 1–250000 px 范围内时调整 iframe，由工作台外层滚动。嵌入成功后的独立页链接放在内容下方，购买和故障时保留上方入口。
