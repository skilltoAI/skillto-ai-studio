# 红白模服务端开发规范

交付对象为 skillto.ai 网站与 API 开发团队。本文是接口设计稿。示例域名、路由、价格和条目用于联调。

## 1. 官方页面与本机录入

| Topic | 列表来源 | 点击后的主区 | 登录与权益 |
|---|---|---|---|
| 官方免费 | skillto.ai 公共目录 API | iframe 内的 skillto.ai 线上 Topic 页面 | 页面、完整提示词、封面和视频均可匿名访问 |
| 官方付费 | 同一公共目录 API | iframe 内的 skillto.ai 线上 Topic 页面 | 页面、简介、公开宣传封面、价格和购买入口均可匿名访问。正片和完整提示词需要购买权益 |
| 本机 | STASS 本机数据，经 MCP 添加 | STASS 原生 Topic 卡片 | 采用现有 STASS 访问边界，仅保存本机 |

官方目录为默认组。进入红白模库时，优先恢复有效的 `assetTopic` URL 选择，否则打开云端指定的官方免费 `defaultTopicId`。本机 Topic 在「本机」组显示，支持本机范围的搜索和聚合。工作台的主区始终嵌入官方 Topic 页面，由 skillto.ai 渲染官方卡片。若需「全部红白模」作为官方默认入口，发布一条独立的云端免费聚合 Topic，只收录可公开的官方条目。

## 2. 下发与页面 JSON

- [Topic List JSON Schema](topic-list.schema.json) 含 skillto.ai 下发示例和 STASS 合并示例。`view=cloud` 仅含在线 Topic，`view=merged` 可含本机 Topic。官方条目均为 `origin=cloud`、`renderMode=iframe`、`requiresLogin=false`。`access` 取 `free` 或 `paid`，表示**内容**的访问等级。
- [Topic Page JSON Schema](topic-page.schema.json) 用 `kind` 区分嵌入描述、线上免费内容、付费待解锁、付费已解锁和本机内容。文件底部有六份示例。
- 云端使用 `sto_`，本机使用 `loc_`。Topic ID 不随名称、排序和访问等级变动；可见数据变化时递增 `revision`。服务端校验列表 ID 唯一、默认 ID 指向列表中的官方免费项、`cloudValidUntil` 晚于 `generatedAt`。官方目录为空或尚未同步时，默认 ID 为 null。
- 左侧官方组在前，组内按 `position`、`id` 排序。付费 `itemCount` 固定为 null，列表仅提供公开宣传封面。免费 `itemCount` 为 Topic 内总数。分页游标绑定 Topic、revision、授权范围及位置。最后一页返回 null。提示词保留原文与换行，作为纯文本渲染。
- 管理后台保存所有素材元数据。STASS 只请求官方目录和嵌入描述。免费条目的完整 JSON 由 skillto.ai 线上页面在自身 Origin 加载。付费完整 JSON 只向通过权益检查的线上页面会话发出。

## 3. Skillto.ai 实现接口

| 方法与拟定地址 | 响应 | 授权 |
|---|---|---|
| GET `https://www.skillto.ai/api/v1/red-white/topics` | Topic List，`view=cloud` | 匿名 |
| GET `https://www.skillto.ai/api/v1/red-white/topics/{id}` | Topic Page，`kind=cloud-embed` | 免费、付费均可匿名读取。只含 Topic 摘要及 `embed.url`、`embed.externalUrl`、协议版本 |
| GET `https://www.skillto.ai/red-white/embed/topics/{id}` | 嵌入专用的线上 HTML | 免费、付费均可匿名打开 |
| GET `https://www.skillto.ai/red-white/topics/{id}` | 同一 Topic 的独立 HTML | 免费、付费均可匿名打开 |
| GET 页面自身 Origin 下的 `/api/v1/red-white/topics/{id}/content` | 免费为 `cloud-public`。付费为 `cloud-locked` 或 `cloud-unlocked` | 免费匿名。付费默认返回公开摘要和报价，有效观看权益才返回已解锁响应 |

目录与嵌入描述支持 ETag、`If-None-Match`。建议目录有效期 5 分钟。STASS 服务端按正式配置中的 HTTPS Origin 和固定路径拉取，启动后后台刷新，手动刷新复用同一流程。首次进入页面先检查本地快照，详情可按需请求。304 沿用现有有效期，过期后执行无条件刷新。完整校验后原子替换快照，移除下架条目的描述缓存。云端目录过期或网络失败时提供重试，已有本机内容保持可用。

Topic 下架返回 `404 TOPIC_NOT_FOUND`。详情或内容可带 `revision`；不匹配返回 `409 TOPIC_REVISION_MISMATCH` 并引导刷新。游标非法返回 `400 INVALID_CURSOR`。付费内容在无权益时给公开锁定响应；锁定响应不含源链接、付费条目或完整提示词。个性化、已解锁和权益验证失败的响应使用 `Cache-Control: private, no-store`，避免 CDN 在不同访客间复用。公共描述永远不根据访客的购买状态改变。

## 4. Feishu 媒体与匿名购买

- 免费、本机条目保存标题、说明、标签、原始提示词、封面及出处。飞书优先用 `video.mode=source-page`，保存稳定文档 URL 和 `fileToken`。稳定直链可用 `mode=direct` 和 `url`。校验 HTTPS、确切媒体主机及允许路径，约束响应大小、类型、范围和重定向。文档可读和视频可播放分别验证。临时签名、匿名 Cookie 和媒体字节沿用受控读取边界。
- 首发付费专题整题售价人民币 9.00 元。验证观看权益后返回完整提示词和可复制的飞书来源链接，保留条目定位锚点。只保存来源元数据，视频由飞书托管。退款或下架后停止站内交付，已经复制的 URL 继续受飞书分享权限控制。上架前核对免费来源是否包含付费条目。
- 新购采用 Skillto.ai 账号结账。未登录用户先进入统一登录流程，授权成功后回到同一专题确认购买。订单绑定稳定用户 UUID，支付验签、到账金额、币种和环境均由服务端校验，支付后同账号查收，退款撤销权益。已发行的访客订单沿用存量权益判断。
- 嵌入场景可由用户点击打开顶层购买页，父页面也保留 `?buy=1` 作为后备入口。浏览器分区登录状态时，已购用户可以在独立页观看。

## 5. STASS 本地 MCP

沿用 `ai_assets_action` 和 `arguments`。云端对象为只读。新增、关联、编辑和删除仅作用于本机 Topic 或经现有 ingest 校验的本机素材。

| 动作 | 输入和返回 |
|---|---|
| `topic_list` | 合并列表 |
| `topic_get` | 输入 `topicId`。官方只返回 `cloud-embed`，本机返回 `local-catalog` |
| `topic_create` | 输入 `requestId`、`title`，可带 `summary`、`position`、`assetIds`、`dryRun`。创建空 Topic 或关联已登记的本机红白模 |
| `topic_update` | 输入 `topicId`、`expectedRevision`、`requestId`、`patch`，可带 `dryRun`。支持名称、简介、排序及 `assetIds` 全量替换 |
| `ingest` | 兼容已有 `source`、`items`。可新增 `topicId`、`expectedTopicRevision`、`requestId`，将新录入或已去重的红白模视频与本机 Topic 原子关联 |
| `topic_delete` | 输入 `topicId`、`expectedRevision`、`requestId`。删除 Topic 及其关联，保留素材和其他 Topic 的关联 |

示例为先创建本机 Topic，再向同一个本机 Topic 录入影片。以下使用合成的飞书链接和 token。

```json
{
  "arguments": {
    "action": "topic_create",
    "requestId": "demo-create-1",
    "title": "我的红白模参考",
    "dryRun": false
  }
}
```

```json
{
  "arguments": {
    "action": "ingest",
    "requestId": "demo-ingest-1",
    "topicId": "loc_personal_demo",
    "expectedTopicRevision": 1,
    "dryRun": true,
    "source": {
      "url": "https://my.feishu.cn/wiki/DemoSourceExample",
      "title": "公开素材示例",
      "access": "unverified",
      "checkedAt": "2026-11-20T08:00:00Z",
      "note": "合成示例"
    },
    "items": [{
      "library": "red-white",
      "title": "动作参考示例",
      "sourceBlockId": "DemoBlock",
      "description": "动作素材",
      "prompt": "固定镜头，完成示例动作。",
      "filename": "demo.mp4",
      "fileToken": "SYNTHETIC_FILE_TOKEN",
      "playback": "unverified"
    }]
  }
}
```

实际用创建响应的 `topic.id` 和 `revision` 填入录入请求。`dryRun` 返回校验结果与预期影响，跳过持久化。验证通过后提交同一请求并关闭 `dryRun`。按客户端、动作和 `requestId` 校验幂等，重复成功写入回放原响应，内容不同报冲突。录入与关联共同提交，版本冲突时无部分写入。校验归属和素材库，拒绝向官方 Topic 写入及把付费素材关联为本机素材。现有无 `topicId` 的录入行为继续可用。

旧飞书分组迁移到本机组，保留文档标题、条目关系与旧 `assetTopic` 别名。已明确映射到官方的专题才跳转到对应官方页面。联调至少覆盖匿名官方目录、匿名免费播放、匿名打开付费页面、未购和已购、退款撤销、本机创建与录入、幂等、旧链接、第三方 Cookie 禁用和离线本机访问。

页面美术与 iframe 接入见 [网页美术风格设计规范](网页美术风格设计规范.md)。

接入项目可按[红白模官方专题接入指南](红白模官方专题接入指南.md)接入生产目录和页面。

付费锁定内容 API 只读投影公开的 `previewItems`，字段为素材 ID、标题、顺序、静态截图封面和原提示词前 50 个 Unicode 字符。UI 追加「付费解锁」，视频源 URL、来源页、文件标识和完整提示词留在服务端。预览游标与已解锁游标分别校验。

官方页面使用 Skillto.ai 同源媒体接口在线播放和下载。原始来源文档 URL、上游视频地址和文件标识只供服务端请求使用。免费与已解锁内容仅返回 `video.playbackUrl`。匿名购买前请访问锁定预览，媒体请求逐次校验专题上架状态、归属和支付权益。
