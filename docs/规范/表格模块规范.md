# 表格模块规范

适用触发：表格、字段、筛选、标签、评分。路径提示：`skills/skillto-ai-studio-table/**`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 保留知识库/项目/表格三级 CRUD、稳定 ID、非空删除确认、九种字段类型和未知导入字段。保留行/表历史、删除快照、导入导出及血缘字段。

- 类型化筛选按 AND 组合；数字边界含端点，null 不当作0；日期错误提示，隐藏列仍可筛选。列偏好按表隔离。

- 标签 CRUD、多选、新建、改名保持关联，移除一个标签不影响其他字段。评分理由、标签、候选图人工选择相互独立；替换图片清除其旧选择。
- STASS 评分列直接显示五颗黑色小星（14px 图形、15px 星位、总宽75px），未选部分浅灰；参照 Ant Design Rate 的半星、悬停预览及再次点击当前分值清除交互。鼠标/触屏直接选择0.5–5分，立即保存；方向键按0.5步进，Home/Delete清除，End选5分。保存中防重复提交，失败回显已保存值并提示；评分说明入口保留。只写score，保留理由、标签、字段和媒体；null表示未评分，拒绝0、布尔值、非半分、非有限数。网页、MCP和原评分说明弹窗均支持半分；旧整数评分兼容，不迁移或自动改写既有评分。此能力不推定远程AMD-PAD已支持。

- 保留视频单元格/悬停/全屏与触屏预览、short_video_info、图片预览。新表仅提供 schema 和记录即可使用控件；网页和 MCP 双向回读。

- 保留已有账号基准规则；表级 dataLineage 的 sources/methods/rules/destinations 及历史不得漏迁。

- 字段排序列出全部已定义字段及「评分」，支持上移、下移和移到首列。业务字段顺序保存到 fields，评分位置以可选 ratingBeforeField 字段名锚点保存（空或缺失保持原尾列位置），不向 schema 或行字段注入评分。保存同时校验原字段顺序与评分位置，保留字段值、评分理由、显示偏好和历史；隐藏锚点字段时评分仍按完整字段顺序定位。标签和编辑仍为固定操作列。旧客户端仅排序业务字段时保留评分位置，旧表无需迁移。
- 可编辑文本字段「人工处理备注」支持单元格内多行编辑与显式保存。请求只更新该字段，并校验打开时的值。保存失败保留输入，避免用旧页面覆盖已有内容。

- STASS 通用评分筛选提供全部/已评分/未评分和0.5–5分范围（半分步进、边界含端点），与字段、搜索和标签按AND组合；倒置或非法范围显示错误。支持单独移除和清除全部，按表隔离，仅改变当前视图。点击评分表头先降序、再升序，未评分始终置后，同分稳定；显示方向及aria-sort。保存评分后立即重新应用当前评分筛选和排序，保持评分列位置与其他行内容。

- 可编辑文本字段「用户修改意见」直接显示多行输入框，停止输入或离开输入框时自动保存。输入法组字结束后才保存，失败保留输入并可重试。保存校验编辑前的字段值，只写本次意见字段并保留换行。

- 通用表格和洗稿内嵌分镜表按页面流展开，无表格内滚动条。宽表使用左右按钮或触控横滑浏览字段。先筛选、排序再分页，每页仅可选 20 / 50 / 100 行，默认 50 行。搜索、筛选、排序或每页行数变化时回到第一页。分页仅改变浏览视图。内嵌分镜可定位到其他页的当前镜头。

- 表格左栏按表名、说明和目录路径搜索，支持近 1 小时 / 8 小时 / 1 天 / 3 天 / 7 天 / 30 天的滚动范围，可同时使用关键词和时间条件。保留命中表格的三级路径。目录可按原顺序或修改时间升降序展示，上级按当前排序方向的第一张匹配表定位，同级时间相同走原顺序。网页目录从表格文件的最后写入时间读取修改时间，不写入目录或表格数据。筛选不改变当前打开的表。

- 目录搜索、修改时间和排序收纳在「知识库」标题行的筛选图标中。鼠标悬浮可预览，点击或键盘激活后可操作，点击外部或按 Escape 收起。收起后保留已生效的条件，图标提示当前筛选或排序已启用。
