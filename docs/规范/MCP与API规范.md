# MCP与API规范

适用触发：MCP、API、客户端、权限。路径提示：`apps/stass/**/mcp*; scripts/*client*`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 所有子技能工作台 CRUD、素材和任务操作均经 MCP；禁止直接 REST、SQL、JSON 修改或导入服务端存储实现。客户端不接受数据根目录作为连接方式。

- 保留表格工具语义，补齐各模块语义工具、能力发现、权限、修订冲突和错误反馈。HTTP 使用标准 Streamable HTTP，提供纯客户端 stdio 桥接。不得通过万能 SQL、路径读写或任意命令工具绕过业务权限。

- 网页 API 和 MCP 共用业务逻辑。凭据不进入 URL、日志或仓库；校验 Origin/Host。生产执行与 CRUD 授权独立；失败不得回退本地文件。

## 同机多宿主

- Codex、Claude、OpenClaw 各自获得独立可撤销的客户端令牌，连接同一实例；注册表仅存令牌摘要，令牌文件留在本机用户配置目录，不进入包或 Git。
- 宿主令牌仅可访问 MCP，禁止用它绕过 MCP 调用业务 REST。撤销实时生效，不要求服务重启。
- stdio 桥接器只加载连接配置，经健康身份核验后调用 HTTP MCP；不导入业务存储、不访问数据目录、不启动另一套服务，也不在连接失败时退回本地读取。
- 当前桥接器透传已实现的工具发现和调用；不能声称已实现未注册的资源或宿主原生配置。协议客户端测试与真实宿主会话验收分开记录。
