# 数据与资源规范

适用触发：数据、素材、文件、数据库、导入、导出。路径提示：`apps/stass/**/storage*; apps/stass/**/media*`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 服务独占工作台数据，保留 JSON/SQLite 等现有存储引擎、稳定 ID、未知字段、历史、删除快照、评分和人工选择。

- 素材以资源 ID 管理；跨机返回可访问媒体 URL，不能把服务端绝对路径当成客户端路径。上传下载经受控分块传输，验证路径、大小、归属及完整性。

- 技能自身说明、静态资源、用户输入和临时文件可以本地处理；工作台业务数据不能直接访问。一次性迁移工具仅可读取明确指定的旧数据源，不作为日常绕过 MCP 的通道。

- 保留来源 URL 和历史原文，不将远程引用标记为已下载。运行数据、媒体、密钥、配置、EXE 和迁移报告不进入 Git。

- AI红白模库仅保存元数据、原始提示词、来源归属和匿名验证状态；视频保留飞书，通过专用流式路由在线转发，不落服务端视频缓存。精确去重保留多个来源，公开分享不等于永久授权。详见 [AI资产模块规范](AI资产模块规范.md)。
