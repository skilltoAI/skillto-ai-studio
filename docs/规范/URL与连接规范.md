# URL与连接规范

适用触发：URL、短链、端口、配对、跨机。路径提示：`apps/stass/**/routing*; apps/stass/**/client*`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 默认 http://<IP>:8080/STASS/，端口可配置；端口被占用时明确报错，不停止其他程序或静默换端口。所有服务路径使用 /STASS/ 前缀。

- 页面使用 t/r/w/b/m 加10位 Base62 短 ID；保留内部 UUID，唯一约束冲突重试，删除后不复用。复杂视图保存为不可变记录，通过 /STASS/s/<短ID> 分享。禁止把凭据、文件路径或状态 JSON 塞入 URL。

- 普通视图通过浏览器历史与按实例/对象隔离的偏好恢复；导航、刷新、前进后退一致。MCP 为 /STASS/mcp，健康接口为 /STASS/health，模块 API 为 /STASS/api/v1/<module>/。

- 解析完整 URL 的真实主机和端口，核验服务标识、实例 ID、版本和能力后配对。显式 URL 优先，其次显式选择实例，最后唯一默认实例；不扫描局域网，不猜测多实例，不在失败时换目标。短链接不代表公开授权。
