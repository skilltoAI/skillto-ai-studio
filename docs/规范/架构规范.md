# 架构规范

适用触发：架构、目录、依赖、隔离、服务边界。路径提示：`apps/stass/**`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 工作台程序源码统一归属 apps/stass，技能源码仍归属 skills。程序拥有 Go 启动器、Python 服务、原生 JS/CSS、模块 API、MCP Server/Client、任务和存储。程序不得通过技能安装目录或开发者绝对路径导入实现。

- 网页和 MCP 共用业务层、权限、历史、锁和事务。子技能只能经 MCP 操作工作台；浏览器和工作台扩展可以调用模块 API。不得静默替换原有外部工具、收费服务或授权边界。

- 保留全部九个入口、实际业务能力和原视觉交互。Creator MCP、Qwen 等外部系统不因端口相同就视为 STASS。
