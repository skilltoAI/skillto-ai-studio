# Motion模块规范

适用触发：Motion、模板、索引、渲染。路径提示：`skills/skillto-ai-studio-motion/**`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 公开工作台使用经发行验收的「AI资产」顶栏，Motion 模板能力由该入口访问。保留既有 Motion 深链及功能，并用实际运行发行包验证导航和深链行为。

- 保留源目录与收藏分离、稳定来源/画幅身份、事务录入、索引与语义检索、标签和证据。索引命中不能冒充已录入、可下载或可运行。

- 保留半星评分、人工/默认来源、已浏览状态、筛选排序、多选、Path/URL、封面与视频、倍速、详情上下条和制作历史。浏览状态不由评分反推；来源运行次数与个人制作独立。

- 迁移原包、预览缓存、索引、制作实例、工程和输出；迁移本身不重编码。制作继续遵守已支持引擎边界、有界队列、取消所属进程树、失败留日志和旧输出、重试新任务。

- Path 指服务机器路径；跨机用户通过资源下载，不能声称客户端也存在该路径。

## AI资产导航兼容

Motion 模版现在位于「AI资产」下，保留 `section=motions` 和原筛选参数，缺省子库仍为 Motion。其他资产库由 [AI资产模块规范](AI资产模块规范.md) 管理，不能套用 Motion 的本地包/媒体缓存策略或执行权限。切换子库必须清理旧轮询及播放，异步挂载不能重新启动已退出页面的计时器。
