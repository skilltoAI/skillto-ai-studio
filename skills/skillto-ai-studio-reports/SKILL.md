# Skillto-AI-Studio · 报表

Manage the local report workspace through the 8880 HTTP API. The report tree is **knowledge base > project > report** and reuses the table workspace's stable knowledge-base and project IDs. A report has its own stable UUID and a Metabase dashboard ID. Read [the API and data contract](references/report-api.md) before writing.

Use `scripts/report_cli.py` or the equivalent HTTP routes for report CRUD. The same routes power the browser. Never edit `reports/catalog.json`, PostgreSQL, or the Metabase application database directly for routine CRUD. Do not put Metabase administrator credentials or guest-signing secrets in prompts, URLs, or generated reports. The local service reads protected credentials outside the repository.

For a request to create or update a report, first read `/api/reports/catalog` to find the intended knowledge base, project, and existing report. Create the report, then create or update its Metabase cards and dashboard layout through the content operation. Read the dashboard back and verify the selected report renders at `http://127.0.0.1:8880/?section=reports&report=<reportId>`. For archive or restore, verify both the Metabase state and report tree. If the Metabase service is unavailable, stop and report the error; never write a local-only registry change.

The two AI teaching-account reports use the frozen 2026-11-07 tag roster. September and October are based on each video's Beijing publish month, with interaction counts observed on November 7. Show coverage and missing values; do not present partial counts as complete. The November 7 account snapshot uses profile total received likes and followers, not recent-video like sums. The raw collection and database sync are separate bulk workflows in the table skill's `reporting/` directory; rerun them only when the user asks for data refresh.

For display, use the signed guest embed generated by the 8880 service. Guest embeds are read-only. Content CRUD uses the service API; the browser also links to the Metabase editor for a person with a Metabase login.
