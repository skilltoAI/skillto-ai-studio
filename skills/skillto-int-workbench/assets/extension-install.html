插件自动连接此工作台，无需填写地址、端口或连接码。

已经安装：重新加载一次

打开 Chrome 扩展管理，找到原有的猫抓修改版（重新加载后显示「SKillto.ai|工作台」），点击卡片上的圆形刷新图标「重新加载」。然后回到视频页，刷新页面，再点击工具栏上的绿色 Logo。

首次安装

  1. 在 Chrome 扩展管理右上角开启「开发者模式」。
  2. 点击「加载已解压的扩展程序」，选择下方目录。
  3. 点击工具栏的拼图图标，把「SKillto.ai|工作台」固定到工具栏。

手动入口：在 Chrome 地址栏输入 chrome://extensions。

开始使用

  1. 打开视频页，点击工具栏的绿色 Logo，等待「已自动连接本地工作台」。
  2. 勾选下载授权，点击「浏览器下载当前视频到拉片」，首次使用时允许 Chrome 下载权限。也可先扫描、预览，再下载所选资源。
  3. 点击「打开拉片并播放视频」，查看视频、分辨率、大小和时长，并整理笔记。

网络发现需要 Chrome 的站点访问确认。此版本仍不读取 Cookie，也不绕过登录、验证码或 DRM。
