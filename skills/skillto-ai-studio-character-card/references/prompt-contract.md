# 定妆照／角色卡提示词的直接引用合同

下面的 `{{image_1}}` 与 `{{image_2}}` 是示意：写入节点前必须按实际连线、模型引用语法和保存顺序替换。`{{image_1}}` 应直接指向函数输入的**新角色X照片**；`{{image_2}}` 应直接指向**原视频待替换角色X的关键帧**。不能只写“上图”“参考图”“角色卡”而不附引用，也不能将第二图当身份图。

## 同时生成定妆照和角色卡

```text
生成【新角色X（{{image_1}}）】的定妆照角色卡：同一新角色的主定妆照、正面／侧面／背面三视图，以及适合该主体的表情或状态细节图。所有视图中的主体必须是同一个【新角色X（{{image_1}}）】。
将【原视频待替换角色X（{{image_2}}）】的〈画面证实的必要服饰或道具〉移植或转译给【新角色X（{{image_1}}）】，保持〈具体功能和位置／动作要求〉。从{{image_2}}只取这些服饰道具，不取原角色的脸、体型、毛发、颜色或其他身份特征。
保留【新角色X（{{image_1}}）】原照片的形态、颜色、材质、纹理与照片／插画／Q版等原有视觉风格；按其实际形态适度拟人化，以完成所需动作和情绪表达，不强制变成人或改变物品本体。
最终图中只能出现【新角色X（{{image_1}}）】的形象；不得出现【原视频待替换角色X（{{image_2}}）】的形象，也不得出现其他角色、文字或水印。
```

把 `X` 换成本次稳定角色编号。第二句的服饰／道具必须由 AI Host 依据原片帧填写具体物件；没有必须保留的物件时，去掉第二图连线及所有 `{{image_2}}` 句子，并把末句改为“最终图中只能出现【新角色X（{{image_1}}）】的形象，不得出现其他角色、文字或水印”。

## 输出形态

- 仅定妆照：首句要求单幅主体造型照，明确可辨面部或结构、全身／整体轮廓和适当服饰道具；不要求三视图。
- 仅角色卡：首句要求正、侧、背三视图和适用的表情或状态细节；不要求额外主照。
- 定妆照角色卡：使用上面的合并模板。对缺少自然面部的物品，用朝向、开合、姿态或局部可动状态表达“表情”，保留本体结构；对卡通照片保留卡通风格，不擅自转写为真人照片。

输出比例、分辨率和字数由调用方从当次模型节点选项读取；这个技能不固定模型。保存后检查每个引用都对应一条实际连线，且图中只保留目标新角色的身份。
