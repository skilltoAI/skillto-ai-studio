# Skillto-AI-Studio · 深度灰视频复刻拆解

这是 `skillto-ai-studio` 的子技能。当前可执行范围是**前三步：取得原片、逐秒拆解、写新角色复刻提示文档**。深度灰成片、音画分离、角色/场景替换生成在后续要求明确时再扩展；本阶段不得用分析图冒充已完成的深度灰视频。

## 1. 取得原视频

1. 保留用户给出的原始 URL 与视频 ID。读 `skillto-ai-studio` 后，按来源选用相应采集子技能：TikTok 用 `skillto-ai-studio-tiktok-crawler` 核实视频与作者、时长和公开页面元数据；实际媒体下载可用已安装的 `scrapling`/`scrapling-stream`。若直链下载失败而公开页面可正常播放，可用 `scripts/capture_public_player.py` 从普通 Edge 播放器媒体响应保存 MP4；脚本只接受采集子技能已核实的单条视频报告。只处理用户授权访问的内容，不绕过登录、验证码、私密状态或 DRM。
2. 将每条原片单独保存为 `source.mp4`，保留出处、采集日期、下载方式、原页面及文件路径。带时效签名的媒体 URL 不写入交付报告；cookie、令牌和浏览器状态不进入工作区。页面信息可用于核对身份，**不能代替视频画面**。
3. 用 `ffprobe` 核对时长、宽高、帧率、视频/音频轨，确认文件可解码；下载失败则报告已证实的状态，不编造逐秒描述。

## 2. 逐镜头与逐秒拆解

1. 先看完整原片，再用半秒或更密的带时间戳原帧覆盖全部时长。可运行 `scripts/sample_timeline.py` 生成逐帧变化分数和抽帧清单（需 FFmpeg、FFprobe、Pillow），并用 `scripts/make_contact.py` 快速总览抽帧；变化分数**仅用于定位候选切点**，需在相邻原帧里人工确认。动作、视线或机位连续变化不等于硬切。
2. 列出所有可辨原视频角色，给稳定的短 ID，写可见外形、服饰/饰物、首次/最后出现时间；对疑似角色或遮挡保持不确定。每秒都单独记录**每个在场角色**的画面位置、姿态和动作、可见表情/口部、眼睛与眼神目标、可见神态，以及推测的情绪。眼睛看不清或角色离屏时明确写“不可判/离屏”，不填泛化词。
3. 先判定是否真的有多个 scene。一个连续镜头里景别、角度、人物位置或背景可见范围变化仍可属于同一 scene。若有多个 scene，写各自 `第XX.XX秒～第XX.XX秒`、环境、角色与镜头，并逐个写 `第XX.XX秒硬切换`；时刻以原片帧率定位，无法精确到帧时标“约”。若无硬切，明确写“全片一个连续 scene；未见硬切”，不要强行分段。
4. 每个一秒区间 `[n.00, min(n+1.00, 时长))` 都写机位高度/角度、景别、运镜（平移、俯仰、推拉、跟随、手持晃动或固定）以及环境变化。镜头运动与角色在画面内运动分开描述。引用该秒内原帧时间戳；复杂动作或疑似切点增采前后帧。
5. 按 [结构化交付字段](references/analysis-schema.md) 写 Markdown 或 JSON。可见事实与情绪/叙事解释分开；只抽帧观察时说明采样间隔和盲区。不得根据封面、标题、音乐或生成标签推断画面细节。

## 3. 深度灰视频复刻新角色 prompt 文档

**输入**：第 2 步的角色清单、scene/硬切核对结果、逐秒表和原帧证据。**用途**：后续以原片对应的深度灰视频为时序与空间控制，将其中指定的【待替换角色1/2】分别换成用户提供的【新角色1/2】，并换成完全未知的【新场景】；复用已核实的机位、运镜、动作节奏和原音频时间轴。第 3 步只写提示文档，不声称已生成、分析或同步深度灰片与音轨。**输出**：每条视频各一份 `深度灰视频复刻新角色prompt文档.md`。全文连 Markdown 标题、空格、换行和标点不超过 **1000 字符**；只写以下 5 项，其中第 3 项按角色数量省略。

### 3.1 整体概述：第 1 项

标题写 `1.整体【生成的新视频】的概述`。简述【新角色1/2】与【新场景】替换关系、动作/叙事主线、原片时序/机位/运镜/节奏/音轨的同步目标。新场景可能是任意环境，不预设原片地点、色彩或固定道具；只保留叙事动作必需的空间功能。指出原片**可见的**表情、神态、动作或角色关系中，什么可能构成观看的情绪钩子、什么可能增强剧情沉浸；不存在就不写。不要把可能的情绪效果说成已证实的“流量爆发”因果、播放数据或真实心理。

### 3.2 新角色与待替换角色映射：第 2、3 项

1. 标题分别写 `2.【新角色1】应该保留的风格、服饰、道具和神态`、`3.【新角色2】应该保留的风格、服饰、道具和神态`。原片只有一个角色，或第二角色不适合替换时，完全省略第 3 项；第 4、5 项编号不变。超过两个待替换角色时继续使用完整的【新角色N】/【待替换角色N】标签并明确映射。
2. **先锁定替换目标**：明确写 `【新角色N】对应【待替换角色N】`，并给出待替换者在原片/后续深度灰片中的稳定画面位置、前后景层次、相对其他角色的方位、体态/轮廓、独特动作轨迹与遮挡关系。例如“前排左一短发者”“后排右二长毛犬”“画面唯一近镜角色”。识别线索优先使用深度灰可读的轮廓、相对深浅、距离层次和动作，**不依赖颜色、纹理或原片服饰细节**。当前若只有 RGB 原片，写“预计可用的深度灰识别线索”；待深度灰片生成后逐镜头核对，不把预计线索冒充已验证的灰片事实。角色进入/离开或换位时更新位置，避免替错人。若有多名相似角色，须增加足以区分的稳定位置和动作线索；无法辨识时明确标记不确定，不能强行指定。
3. 新角色的物种、年龄、形态、外观均未知，可是动物、真人、婴儿、卡通角色或拟人物品。基于原片角色、动作、表情、眼神、风格和内容，只保留有助于**情绪钩子、故事沉浸和动作同步**的视觉风格、服饰/配件功能、道具功能、身体状态、神情与情绪节奏。没有必留服饰/配件/道具时写“无必留”；不要凭空添加。给新角色充分的视觉辨识空间。**不复述原角色详细外貌、颜色和非必要特征，也不列不保留清单。**

### 3.3 镜头硬切点：第 4 项

标题写 `4.【生成的新视频】的镜头硬切点`。只沿用原片相邻帧核实的 scene 时段与硬切时间。有硬切时逐点写时间、切前/切后机位、景别、运镜变化，以及两侧每个在场【待替换角色N】的深度灰辨识线索与【新角色N】应占的位置；新场景只写相应空间功能。无硬切时写 `0.00～片尾单一连续镜头，无硬切`，再写持续机位/运镜和角色位置变化，不虚构切前切后画面。位置描述必须与第 2、3 项映射一致。

### 3.4 逐秒描述：第 5 项

标题写 `5.【生成的新视频】的逐秒描述`。从 `0.00～1.00秒` 起按第 2 步时间区间逐秒连续写到片尾。每行含**机位、景别、运镜、环境/新场景的空间功能**；每个在场角色均用完整 `【新角色1】`、`【新角色2】` 等标签，分别写**画面位置、动作、表情/口部、眼睛/眼神、神态和情绪推测**。不能缩写成 1/2 或省略主语；相对位置与第 2、3 项映射和第 4 项镜头一致。形态未知时用“可动部位”等可迁移描述，不强加原物种或人体结构。不可判/离屏字段直写“不可判/离屏”；不虚构声音、动机、镜头、具体新场景。

写完后核对：第 1、2、4、5 项齐全；第 3 项只在第二角色适合替换时出现；各【新角色N】与【待替换角色N】一一对应且有可用于灰片核对的位置/轮廓/动作线索；硬切与第 2 步一致；逐秒覆盖片尾、每个在场角色均有完整标签；情绪有画面依据且非流量因果断言；新场景不被预设；总字符数 ≤1000。超长时压缩重复形容词，不删替换映射、逐秒时段或镜头/动作关键信息。

## 交付核对

交付原视频路径、媒体参数、角色清单、scene/硬切清单、逐秒表和每条视频独立的新角色 prompt 文档。每个 scene 时间范围覆盖原片且不交叉；逐秒行从 `0.00` 到片尾连续覆盖；各行可追溯到原帧。外部视频不能取得时，交付采集失败证据与未完成项，不输出虚构拆解。
