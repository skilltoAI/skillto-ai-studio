# 模块化分层视觉设计：风格明细库

本库只收录用户确认的 14 类，不主动扩展。检索入口：[风格索引](style-index.md)。技术入口：[Remotion / Motion 指南](remotion-motion-guide.md)。整理基线：2026-11-17。

## 分类与使用约定

“模块化分层视觉设计”是本库的工作分类，不是统一的美术史流派。每个条目描述美术风格或表现手法；可拆解和元素级动画是全部条目的制作要求。

- **保持开放的变量**：题材、人物身份、物品种类、图片内容、文字、数据、品牌，以及风格没有固有要求的色系。适用场景描述比较、分类、关系、流程、空间揭示等抽象表达需求。
- **允许固有特征**：白模是特定美术形式，可以明确其白色或近白、低纹理的模型表现；这不意味着同条目的所有微缩沙盘都必须白色，也不把白色当成全库默认色。材料、构造和造型的定义性特征同样应保留。
- **不从参考图继承限制**：纸艺不必米白，批注不必朱红，摄影不必去色，微缩模型不绑定某类主体。某次设计的配色与内容应写进该项目的设计参数，而非本库条目。
- **允许交叉**：可选择主风格加辅助手法，例如纸本编排使用线描标记。记录各自编号，并约定一致的透视、尺度、光影与动作节奏。
- **动作粒度**：对象整体、局部部件、柔性表面、真实三维是不同能力。能把一个人物整体移入，不等于能眨眼、摆手或转身。
- **独立控制**：角色、道具、场景分区、图片、箭头、文字、图表、图例均按需要设独立节点。每个节点具有入场、idle、动作、出场槽；idle 可以保持静止。父子、接触、遮挡与连接约束仍须成立。
- **完整素材**：保留透明边缘、干净底板和被遮挡区域；纹理附着主体，投影和连接线可单独控制但跟随物体。单张合成图不等于已分层资产。
- **扩库边界**：当前只有 S001–S014。子形式、别名和技术变体留在原条目内；只有用户要求扩库时才新增编号。

## S001 分层纸雕／纸剧场

- **别名**：纸雕分层叠置、层叠纸雕场景、纸雕立体场景、微缩纸雕剧场、paper theater。
- **美术特点**：纸面切割、舞台框景、前中后景留空叠置，层间阴影与物理厚度制造纵深。加背光形成“光影纸雕”子形式，不另外新增风格编号。
- **空间与构件**：2.5D 或真实三维；舞台框、底板、各层景片、景片内的独立对象、角色、道具、遮挡片、文字、光源分别设节点。近景可有更强视差，层间距离按构图决定。
- **拆解方法**：每张景片保留独立轮廓与孔洞；需要单独移动的对象从景片继续拆出；准备后方净版和移出遮挡后可见的完整边缘。不能把角色、箭头和文字印死在背景里。
- **入场**：景片依次插入、框景展开、角色从遮挡后出现。
- **idle／独立动作**：局部轻摆、有限视差、背光缓变；对象可独立穿行，底板可静止。
- **出场**：抽片、退入遮挡、逐层收拢或分区熄光。
- **适用场景**：空间层次展示；渐进揭示；沉浸叙事；前后关系表达。
- **限制与区别**：平面叠片不能支持任意绕拍；深舞台空间区别于 S009 的浅浮雕。光晕遮罩可以近似背光，但不等于物理透射。
- **技术入口**：[T01 分层纸艺](remotion-motion-guide.md#t01)；明显厚度、绕拍或真实光照用 [T06 三维空间](remotion-motion-guide.md#t06)。

<a id="s002"></a>
## S002 折纸构成／立体书机关

- **别名**：折纸面片、origami、pop-up、翻页机关。
- **美术特点**：可辨识折线、正反纸面和铰接关系。折纸侧重面片折叠；立体书侧重页面开合带动机关竖起与滑动，两者在本条目内区别处理。
- **空间与构件**：2.5D/3D；纸面、折痕、书脊、折撑、拉片、附着对象和文字。
- **拆解方法**：沿折线拆面片，记录旋转轴、正反面、父子层级与开合顺序；纸面图文附着本面但可有独立显隐时间。
- **入场**：翻页、翻起、撑开与折面展开。
- **idle／独立动作**：轻微铰接回弹、局部拉片活动或保持；页角与机关角度联动。
- **出场**：折回、压平、机关归页、合页。
- **适用场景**：结构展开；整体与局部关系；阶段揭示；机制说明。
- **限制与区别**：CSS 刚性面片只适合有限折叠；连续卷曲、穿插与自遮挡需要网格和约束。不能把普通卡片旋转称为完整立体书机关。
- **技术入口**：[T03 折面与翻页](remotion-motion-guide.md#t03)；连续弯曲使用 [T07 表面形变](remotion-motion-guide.md#t07)。

<a id="s003"></a>
## S003 剪纸剪影／关节纸偶

- **别名**：cutout animation、纸偶、剪影偶、关节剪片。
- **美术特点**：概括轮廓、纸片重叠与铰接动作；可用剪影或内部有图案的剪片，不限制主体种类和色系。
- **空间与构件**：2D/2.5D；主体、动作部件、五官、铰接点、道具、遮挡片、投影。
- **拆解方法**：按动作拆头、躯干、四肢或其他结构；在关节处保留遮盖余量；锚点设在连接点，持握道具挂到相应节点。
- **入场**：滑入、跳入、从遮挡后探出或逐片拼合。
- **idle／独立动作**：眨眼、点头、局部摆动；脚、支点或悬挂点保持约束。无表演需求时保持静止。
- **出场**：转向离开、剪片收拢、退入遮挡。
- **适用场景**：角色行为表达；动作示意；对话关系；寓言式叙事。
- **限制与区别**：关节转动不是自然网格变形；二维纸偶转动不能凭空生成背面。与 S001 的空间景片不同，本项以局部表演为核心。
- **技术入口**：[T08 部件与骨骼](remotion-motion-guide.md#t08)；轮廓与描线见 [T05 路径](remotion-motion-guide.md#t05)。

<a id="s004"></a>
## S004 纸本编辑拼贴

- **别名**：editorial collage、纸张摄影拼贴、混合媒介编排。
- **美术特点**：纸片、摄影、插画、标签和笔迹并置，用边缘、留白、错位与覆盖组织阅读；可整齐也可松散，不固定配色和内容。
- **空间与构件**：2D/2.5D；纸底、图片、纸内裁切、边框、图文、笔迹、箭头、胶带与装饰。
- **拆解方法**：图片内容与承载纸分离，标题与批注保留可编辑文字；附件单独建层；每张纸作为父组但内部有独立时间段。
- **入场**：贴入、滑放、压下、逐项组版。
- **idle／独立动作**：照片内缓移、当前标记强调、轻微翘角；正文保持阅读稳定。
- **出场**：抽走、揭起、重新堆叠、分组转移。
- **适用场景**：多来源信息组织；过程串联；观点比较；视觉联想。
- **限制与区别**：翘角模拟需要背面与阴影；只改变旋转角是简化表现。区别 S005 的资料组织语法，本项更侧重综合编辑编排。
- **技术入口**：[T02 拼贴与纹理](remotion-motion-guide.md#t02)＋[T09 排版](remotion-motion-guide.md#t09)。

<a id="s005"></a>
## S005 档案文献／手账拼贴

- **别名**：document collage、档案板、资料卡片、手账编排。
- **美术特点**：叠页、索引、夹具、装订、批注和引线产生资料被整理的秩序感；不绑定真实文献、特定行业或某种纸色。
- **空间与构件**：2D/2.5D；纸页、堆叠边、夹具、图片、标题正文、索引签、注释框与连接线。
- **拆解方法**：每页图文归入该页父节点；夹具和页角保留正确遮挡层级；注释和目标使用显式锚点关系。
- **入场**：递入、开页、逐条展开注释。
- **idle／独立动作**：阅读保持、当前注释轻强调、索引切换；避免全部长文本持续晃动。
- **出场**：归档、合拢、抽页、收回注释。
- **适用场景**：证据组织；信息溯源；层级说明；论证结构；资料对照。
- **限制与区别**：资料感不等于真实性；具体内容的来源另行核实。区别 S004 的自由拼贴；翻页必须补齐被遮挡内容。
- **技术入口**：[T02 拼贴](remotion-motion-guide.md#t02)＋[T09 排版与连接](remotion-motion-guide.md#t09)，翻页选 [T03](remotion-motion-guide.md#t03)。

<a id="s006"></a>
## S006 票券拼贴／纸制品隐喻图形

- **别名**：票券纸艺信息图、纸堆图形、paper-token graphics。
- **美术特点**：齿孔、撕口、纸条、卡片和叠纸将可计数单元、份额与损耗实体化；票面内容与配色自由。
- **空间与构件**：2D/2.5D；单张、叠层、端部、可变中段、票面符号、数字、文字、可撕段与辅助线。
- **拆解方法**：逐张变化时每张一个节点；按长度编码时分离两端、中段和内容；缺失部分与虚线单独建层。
- **入场**：逐张堆叠、连续送入、分段拼接。
- **idle／独立动作**：选中单元轻抬、局部边缘活动；数量变化由同一数据源驱动。
- **出场**：抽离、撕去、散开、分组收回。
- **适用场景**：数量变化；资源分配；累计消耗；比例比较；部分与整体关系。
- **限制与区别**：不能把票面文字随长度拉伸；若张数和长度分别承载数量，先定义统一口径。真实撕裂需要断口而非普通矩形擦除。
- **技术入口**：[T02 拼贴](remotion-motion-guide.md#t02)＋[T04 数据与几何](remotion-motion-guide.md#t04)。

<a id="s007"></a>
## S007 微缩人偶／桌面装置

- **别名**：miniature figurine、微缩摆件、桌面模型装置。
- **美术特点**：主体具有小型实体、模型或雕塑感；统一尺度、支撑关系与落地投影建立空间，不限定人形、材质或色系。
- **空间与构件**：固定视角 2.5D 或真实 3D；每个主体、底座、道具、标牌、关系线、地面投影。
- **拆解方法**：整体位移只需独立透明素材；局部表演需拆部件与五官；转身或换视角准备模型或足够多视图。
- **入场**：放置、升起、转台式显现。
- **idle／独立动作**：雕塑姿态保持、小幅转头、站位变化；主体动作与地面投影保持一致。
- **出场**：移走、下降、分组重排。
- **适用场景**：关系网络；群体分类；角色定位；位置变化；主体对照。
- **限制与区别**：现成图片的光照与视角固定；不能把整体缩放叫作真实呼吸或把平面旋转叫作转身。区别 S008 的结构性模型组织。
- **技术入口**：[T06 三维](remotion-motion-guide.md#t06)＋[T08 表演](remotion-motion-guide.md#t08)；固定视角可选 [T02](remotion-motion-guide.md#t02)。

<a id="s008"></a>
## S008 白模／微缩沙盘

- **别名**：建筑白模、体块模型、massing model、miniature maquette。
- **美术特点**：白模以白色或近白、低纹理的实体表面突出体块、比例、光影与结构，白色是该子形式的定义性特征，可明确提及。微缩沙盘以统一尺度与空间陈列组织构件，可采用其他配色和材料；它不被白模的颜色要求覆盖。
- **空间与构件**：固定投影 2.5D 或 3D；主体体块、层板、外壳、底座、配景、名称牌和阴影。建筑白模是常见子形式，不把所有主体限定为建筑。
- **拆解方法**：按需要独立出现、比较或装配的模块拆分；保留共同尺度、放置面和模型坐标；标签单独排版。
- **入场**：逐层搭建、模块落位、依序陈列。
- **idle／独立动作**：保持或缓慢换观察角度、选中模块轻抬；非选中模块可静止。
- **出场**：拆解、下沉、分组收纳。
- **适用场景**：系统组成；模块分类；规模比较；空间组织；结构总览。
- **限制与区别**：只有明确选用白模子形式才采用其颜色特征；细节量不应破坏体块可读性。与 S007 相比更强调系统结构、比例与模块。
- **技术入口**：[T06 三维空间](remotion-motion-guide.md#t06)；固定投影的简单体块用 [T04](remotion-motion-guide.md#t04)。

<a id="s009"></a>
## S009 浅浮雕／实体化图形

- **别名**：bas-relief、立体信息图、挤出图形、压印图形。
- **美术特点**：图形从承载面凸起或凹入，以厚度、侧面、倒角和接触阴影表达实体感；含凸起、压印与浅挤出子形式，不固定承载材料或颜色。
- **空间与构件**：2.5D/3D；正面、侧面、厚度、凹槽、阴影、数值、文字、坐标轴与辅助线。
- **拆解方法**：每个数据图形独立，侧面随尺寸重算；数字与图例从几何中分离；光照与深度参数保留。
- **入场**：隆起、沿轴生长、压入或分块落位。
- **idle／独立动作**：局部轻抬、光照轻变、单独强调；数据更新驱动对应几何与数值。
- **出场**：回缩、压平、填平或分块移走。
- **适用场景**：数量比较；差额表达；等级排序；结构权重；变化幅度。
- **限制与区别**：区别 S001 的舞台纵深；条形伸缩不能拉伸文字或倒角。简单 CSS 阴影不支持真实凹槽绕拍。
- **技术入口**：[T04 参数几何](remotion-motion-guide.md#t04)，真实倒角与投影用 [T06](remotion-motion-guide.md#t06)。

<a id="s010"></a>
## S010 软陶／黏土模型

- **别名**：clay、plasticine、软陶造型、黏土动画外观。
- **美术特点**：圆润体积、柔和边缘、接合和塑形痕迹；软硬程度按具体形式决定。定格节奏可选，不是必须；不固定颜色或角色类型。
- **空间与构件**：2.5D/3D；主体、部件、五官、道具、纹理、形变目标和投影。
- **拆解方法**：根据整体动作、关节表演或揉捏形变分别准备透明部件、骨骼、网格形态或预制序列。
- **入场**：挤出、团聚、弹落或拼合。
- **idle／独立动作**：轻挤压、呼吸、眨眼或保持；硬质软陶可以选择刚体动作。
- **出场**：缩回、分块移走、揉合或收拢。
- **适用场景**：亲和表达；情绪传递；抽象概念具象化；低门槛知识说明。
- **限制与区别**：透明图片不能真实改变体积；模拟定格需确定性地采样动作，文字可保持稳定，避免全画面无差别抖动。
- **技术入口**：[T07 形变](remotion-motion-guide.md#t07)＋[T08 表演](remotion-motion-guide.md#t08)，体积渲染用 [T06](remotion-motion-guide.md#t06)。

<a id="s011"></a>
## S011 毛毡／织物贴布

- **别名**：felt appliqué、布片拼贴、织物贴花。
- **美术特点**：纤维边缘、缝线、柔软厚度和贴合关系形成触感；织纹、图案与配色可按项目决定。
- **空间与构件**：2D/2.5D/3D；每片布、缝线、纽扣、标签、填充轮廓、纤维边与阴影。
- **拆解方法**：布片各自保留遮罩与纹理坐标；线迹绑定对应布片，同时可独立绘制；连接点与翻面区域明确。
- **入场**：铺放、贴合、缝合。
- **idle／独立动作**：轻摆、软性起伏或保持；被缝住的点不应自由漂移。
- **出场**：揭起、卷收、拆线或分片归位。
- **适用场景**：温暖叙事；陪伴感表达；分类归纳；连接与组合说明。
- **限制与区别**：贴纹理的硬纸片不能自动成为柔软布面；明显褶皱、翻卷需网格或预制形变，线迹要随布面移动。
- **技术入口**：[T02 纹理拼贴](remotion-motion-guide.md#t02)＋[T07 形变](remotion-motion-guide.md#t07)，缝线见 [T05](remotion-motion-guide.md#t05)。

<a id="s012"></a>
## S012 扁平矢量／几何构成

- **别名**：flat vector、色块构成、几何图形动画。
- **美术特点**：简洁轮廓、色块与留白组织信息，弱化实体材质；色块的数量、颜色与语义由项目定义。
- **空间与构件**：2D；独立形状、图标、角色部件、线条、文字、图表与图例。
- **拆解方法**：SVG 按语义分组而非只按颜色合并；保留形状参数、坐标和路径，逻辑组可以整体移动。
- **入场**：生长、滑入、形状拼合、遮罩显现。
- **idle／独立动作**：轻摆、脉冲、保持；单个形状可重排或改变参数。
- **出场**：收缩、分解、形变衔接。
- **适用场景**：流程说明；概念关系；机制演示；信息压缩；快速比较。
- **限制与区别**：复杂路径形变需匹配拓扑或采用额外插值；不能让形变破坏图表数据含义。区别 S013 的线结构优先。
- **技术入口**：[T04 几何](remotion-motion-guide.md#t04)＋[T05 路径](remotion-motion-guide.md#t05)。

<a id="s013"></a>
## S013 技术线描／线框示意

- **别名**：technical line art、wireframe、剖面线描、结构示意。
- **美术特点**：轮廓、网格、剖面、引线和测量标记承担结构解释；不要求蓝底、单色或特定技术题材。
- **空间与构件**：2D 或三维投影；主轮廓、内部结构、剖切面、连接线、节点、标记和文字。
- **拆解方法**：路径按结构分组，端点关联节点锚点；三维线框保留几何与相机；注释始终可独立控制。
- **入场**：描线、节点依次出现、结构逐层展开。
- **idle／独立动作**：沿路径流动、局部扫描、节点强调或保持；结构移动时重算引线。
- **出场**：收线、折叠、逐层隐藏。
- **适用场景**：原理解释；因果链；结构解析；路径传播；精确关系说明。
- **限制与区别**：精密外观不能替代准确数据；二维线稿不能随意绕拍，密集线条需在目标尺寸检查可读性。
- **技术入口**：[T05 路径](remotion-motion-guide.md#t05)＋[T09 标注](remotion-motion-guide.md#t09)，三维线框用 [T06](remotion-motion-guide.md#t06)。

<a id="s014"></a>
## S014 字体构成／字块拼装

- **别名**：kinetic typography、字形构成、排版动效、字块装置。
- **美术特点**：文字同时承担语言和形状功能，以字号、字重、间距、切分、遮挡、排列或实体厚度构图；字体与配色不固定。
- **空间与构件**：2D/2.5D/3D；句、词、字或笔画，背景块、强调线、注解与字块厚度。
- **拆解方法**：按动作粒度分割，同时保留阅读顺序与文本内容；精确笔画动作另备路径，实体字块另备轮廓或网格。
- **入场**：逐词排入、字块落位、遮罩揭示或按笔顺书写。
- **idle／独立动作**：阅读保持、局部字重与色彩强调、单个词重排。
- **出场**：散开、收束、重排到下一构图。
- **适用场景**：观点强调；语义对比；节奏组织；短信息表达；语言结构可视化。
- **限制与区别**：按字出现不等于书写；真正书写需要笔顺。大段文本不宜逐字持续运动；中文、组合字符与双向文字须正确分割。
- **技术入口**：[T09 排版](remotion-motion-guide.md#t09)＋[T05 笔画](remotion-motion-guide.md#t05)，立体字块用 [T06](remotion-motion-guide.md#t06)。
