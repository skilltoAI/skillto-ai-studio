# 视觉系统规范

以下默认值针对 9:16、1080×1920 的抖音、视频号、小红书竖屏。其他画幅按短边等比换算。平台界面会改版，开始前拿一张当前平台的截图核对安全区。

## 安全区

| 区域 | 默认保留 | 放什么 |
| --- | --- | --- |
| 顶部 0–200 px | 状态栏、搜索、直播入口 | 只放背景，不放进度装置和文字 |
| 底部 1500–1920 px | 账号名、标题、描述、音乐条 | 只放背景；字幕基线不低于约 1480 |
| 右侧 940–1080 px，700–1600 高度 | 头像、点赞、评论、收藏、分享 | 不放关键数字和证据 |
| 主读区 x 70–940，y 220–1480 | 标题、证据、数字、人脸 | 所有必读信息 |

进度装置放在主读区上沿（约 y 220–300），或者字幕上方的独立一行，不贴着屏幕顶边或底边。

## 字号下限（1080 宽）

| 用途 | 下限 | 说明 |
| --- | --- | --- |
| 字幕 | 54 px，粗体加描边 | 约为画面宽度的 5%；低于 4% 在手机上吃力 |
| 证据高亮重排句 | 44 px | 原截图正文通常太小，只做背景 |
| 标签、来源行 | 28 px | 可以弱化，但不能看不清 |
| 关键词大字 | 120–220 px | 一屏一个 |
| 数字强拍 | 260 px 以上 | 一屏一个，配一个单位或对比 |

验收办法：把画面缩到 25%（270×480）看，第一眼读到的必须是关键词、数字或人脸，接着能读出字幕。

## 颜色语义

- 一个强调色只表达一种语义（危险、冲击、下降、重点任选其一），全片不换。品牌强调色和语义冲突时（例如品牌绿和“被砍”），用形状和动效承载语义（斜切、裂纹、印章、划掉），不要临时换色。
- 涨跌颜色跟着受众习惯走（中国大陆红涨绿跌），图表里写明方向，不只靠颜色。
- 背景一种主色调，最多加一个辅助暗调。中段连续出现五个以上同色同版式的镜头时，换版式或换背景明度。
- 示意图和真实截图用不同的边框或标签区分。

## 版式

先定 2 到 4 种版式，全片交替使用，每种写清用途。常用组合：

| 版式 | 用途 | 注意 |
| --- | --- | --- |
| 人物全屏 | 承诺、自我暴露、观点、互动 | 标题压在头顶上方，不遮眼和嘴 |
| 证据全屏 | 截图、报道、公告、数据图 | 截图上方写章节标签，下方写来源行 |
| 数字全屏 | 强拍数字、对比 | 一屏一个数字，配一行解释 |
| 留白反问 | 打断、反转 | 只放一句问句，其余留空 |
| 归纳图 | 收束 | 三到五个节点，箭头关系清楚 |
| 人物加信息（上下或画中画） | 需要人脸也需要信息的句子 | 小窗必须有表情或动作价值，否则去掉 |

## 进度装置

- 段数在承诺帧里出现，此后常驻。
- 每段带内容标签，当前段高亮，已过段变弱，未到段为空位。
- 到兑现段时可以让装置本身参与（例如最后一格指向讲者）。
- 结尾在末尾追加一个“下一个？”空位，和互动问题连在一起。

## 证据框

- 外框：浏览器、文档或手机框，顶部显示域名或来源名。
- 内容：真实截图，只保留和本句有关的部分。
- 高亮：一处，荧光底色或下划线；高亮句在框外放大重排一次。
- 来源行：机构或媒体、日期、口径（公司自述、据报道、估算）。
- 没有授权截图时：用文字卡加“据报道”标签，不仿造网页。

## 动效

- 每种语义一种动效，全片固定：例如“被砍”用斜切，“下降”用曲线断崖，“结论”用盖章，“对比”用左右滑入。
- 强拍动效 6 到 12 帧完成；弱拍用淡入或静止。
- 复杂动效优先复用 `video-talkcraft` 等动效库里匹配的源码，并记录用了哪个配方。
