# 深度灰复刻新角色提示文档合同

输入是 `原视频视频分镜细节.md` 的角色、scene、硬切和逐秒原帧证据。每条原片一份 `深度灰视频复刻新角色prompt文档.md`。目标是用深度灰片控制原动作和机位，将【待替换角色N】映射到用户后续给出的【新角色N】并置于未知【新场景】；不预设新角色是人、动物或物品，也不预设新场景颜色地点。

文档固定如下条目，编号不因省略第 3 项而重排：

1. `1.整体【生成的新视频】的概述`：动作与叙事主线、原片时序/机位/运镜/节奏/音轨同步目标；仅依据可见画面指出可能的情绪钩子，不声称已证实流量或心理因果。
2. `2.【新角色1】应该保留的风格、服饰、道具和神态`：先写 `【新角色1】对应【待替换角色1】`，再写跨镜头可辨的位置、前后层次、轮廓、动作轨迹、遮挡；只保留有助动作和叙事的服饰/道具功能与神态。无必留物写“无必留”。
3. 有第二待替换角色时写 `3.【新角色2】应该保留的风格、服饰、道具和神态`，按第 2 项同样建立一一映射；没有则完全省略。更多角色继续使用完整的 N 标签。
4. `4.【生成的新视频】的镜头硬切点`：只写相邻原帧核实的切点，附切前后机位、景别、运镜和各目标位置；没有切点写 `0.00～片尾单一连续镜头，无硬切`。
5. `5.【生成的新视频】的逐秒描述`：从 `0.00～1.00秒` 至片尾连续覆盖，逐秒写机位、景别、运镜、新场景的空间功能，以及每个在场【新角色N】的位置、动作、表情/口部、眼神、神态和有依据的情绪推测。不可判/离屏直接标明；不强加人类肢体结构。

角色识别只在实际深度片中核对后才可称“已验证”；目前只有 RGB 原片时写“预计可用的深度灰识别线索”。原角色颜色或非必要外貌不得替代新角色特征。目标提示文档连标题、空格和标点不超过 1000 字符；如果较长视频的逐秒覆盖使限制不可同时满足，保留完整分镜证据并明确报告，不删关键秒段来凑数。

## 输出骨架

写作时把所有 `<...>` 换成原帧可证实的内容；没有第二角色就整段删除第 3 项，但保留第 4、5 项编号。此文档是复刻指导，不是新角色照片理解 JSON，也不是视频生成任务完成证明。

```text
1.整体【生成的新视频】的概述
<新角色与未知新场景的替换目标；原时序、镜头、运镜、动作和可用音频的同步目标；画面支持的情绪钩子>
2.【新角色1】应该保留的风格、服饰、道具和神态
【新角色1】对应【待替换角色1】；<可辨位置/轮廓/动作/遮挡>；<必留功能或“无必留”>。
3.【新角色2】应该保留的风格、服饰、道具和神态
【新角色2】对应【待替换角色2】；<仅在第二角色存在时写>。
4.【生成的新视频】的镜头硬切点
<经相邻帧核实的各切点及切前后机位/角色位置；无硬切则写0.00～片尾单一连续镜头，无硬切>
5.【生成的新视频】的逐秒描述
0.00～1.00秒：<机位/景别/运镜/空间功能；每个在场【新角色N】的位置/动作/表情/口部/眼神/神态/情绪推测>。
1.00～2.00秒：<依次写到真实片尾，不跳秒>。
```
