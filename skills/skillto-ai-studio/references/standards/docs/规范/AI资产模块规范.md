# AI资产模块规范

适用：AI资产、AI红白模、剪映AI模版，`apps/stass/ai_asset*`、`assets/ai-assets.*`、`skills/skillto-ai-studio-assets/**`。

- 顶部原 Motion 模版入口显示为「AI资产」，下设「Motion 模版」「AI红白模库」「剪映AI模版库」。内部保留 `section=motions` 与全部 `motion_*` 参数；新增 `assetLibrary=motion|red-white|jianying`，缺省为 Motion，旧链接、筛选、标签、评分、生产任务及数据保持兼容。
- 红白模左侧 Topic 按飞书来源文档 ID 分组、使用文档标题，全部视图按卡片去重。多来源卡片在各自 Topic 中可见。Topic 与搜索组合，URL 的 assetTopic 记录选择，窄屏改为横向筛选栏。
- 红白模每卡同时展示提示词和可播放视频、提示词复制 icon、视频下载 icon，包含可读名称、来源与状态。长提示词可滚动/展开，复制保留全部原文。可见卡片按需加载视频首帧，切换时释放媒体和轮询。键盘、窄屏、前进后退和刷新均可用。
- `ai_assets_action` 是当前 MCP 元数据读写入口，参数放入 `arguments`，动作 `catalog`/`ingest`。先 dryRun，按来源和 block ID 幂等录入，整批校验后写入。元数据、提示词与来源验证状态保存在服务数据根 `ai-assets.json`；实际视频不落服务端本地。
- 来源只接受 `https://my.feishu.cn/wiki/<token>` 或 `/docx/<token>`。每项保存来源、原始提示词、视频引用及访问检查时间。相同库/标题/完整提示词/文件名/视频摘要才聚合卡片，保留所有来源；无摘要时按视频引用判断，不凭标题去重。
- 来源匿名可读与视频匿名可播放须分别验证。运行时使用全新访客浏览器上下文取得飞书匿名授权，不使用用户档案或登录凭据。仅内存短期缓存匿名请求头，禁止记录 Cookie；公开权限变化时返回明确错误，不绕过登录。
- 专用 `/STASS/api/v1/ai-assets/media/{id}` 流式路由直接转发飞书视频，支持单段 Range、206 和 `download=1` 附件下载；不经过会写临时文件的通用网页适配器。仅固定 HTTPS 视频域，禁止重定向，检查 MIME/大小，断开或异常时关闭上游；浏览器主动下载才保存到用户下载位置。
- 预览、复制和资产录入不授权运行提示词、付费生成或发布。Motion 下载与执行仍遵守 Motion 子技能原边界；剪映库无来源时真实为空。收集到的提示词、源响应和媒体不得提交 Git。
- 验收包括匿名播放/拖动/下载、复制原文、重复录入与多来源去重、错误恢复、导航回归、窄屏，以及服务端没有新增媒体文件。保留原表格和 Motion 数据。

- 官方红白模目录从 skillto.ai 服务端读取，内嵌 www.skillto.ai/red-white/embed/topics/ 专用页面；本机来源分组与离线浏览继续保留。首发十一月 10 条免费，九月去重后 12 条、人民币 9 元。浏览器只将公开挑战 ID 带往顶层，飞书链接由线上页面在用户权益验证后交付。

- 官方专题按 API 返回顺序展示并默认选中云端指定免费项。官方专题和本机分组使用独立选择键，旧链接按已知映射解析，刷新及前进后退均恢复当前分组。生产嵌入限已登记的 `http://127.0.0.1:8080`，其他工作台地址显示官方独立页入口。
