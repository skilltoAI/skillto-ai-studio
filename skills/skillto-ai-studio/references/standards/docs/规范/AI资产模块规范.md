# AI资产模块规范

适用：AI资产、AI红白模、剪映AI模版，`apps/stass/ai_asset*`、`assets/ai-assets.*`、`skills/skillto-ai-studio-assets/**`。

- 顶部原 Motion 模版入口显示为「AI资产」，下设「Motion 模版」「AI红白模库」「剪映AI模版库」。内部保留 `section=motions` 与全部 `motion_*` 参数；新增 `assetLibrary=motion|red-white|jianying`，缺省为 Motion，旧链接、筛选、标签、评分、生产任务及数据保持兼容。
- 红白模左侧显示独立本机 Topic 和飞书来源分组。无视频的本机 Topic 仍可见。飞书来源继续按文档 ID 分组，多来源卡片在各自分组中可见。Topic 与搜索组合，URL 的 assetTopic 记录选择，窄屏改为横向筛选栏。
- 红白模每卡同时展示提示词和可播放视频、提示词复制 icon、视频下载 icon，包含可读名称、来源与状态。长提示词可滚动/展开，复制保留全部原文。可见卡片按需加载视频首帧，切换时释放媒体和轮询。键盘、窄屏、前进后退和刷新均可用。
- `ai_assets_action` 接收 `arguments`。录入本机视频使用 `create_topic`、`begin_upload`、`upload_chunk`、`finish_upload`，支持取消未提交上传。创建 Topic 和开始上传可 dryRun；使用稳定条目键、顺序字节偏移和 SHA-256 支持幂等与重试。MP4 完整校验后才入库到当前实例管理的数据根。服务只接收客户端发送的字节，禁止代读客户端指定的任意服务端路径。
- 通过 `set_cover` 指定已入库本机 MP4 的 `itemId` 和帧时间 `timeMs`。服务生成 960×540 居中裁切的 JPEG，沿用同源媒体权限，通过 `?cover=1` 展示为视频封面。目录用 `hasCover` 标记已生成的封面。原 MP4、提示词和播放画幅保持原样，旧条目使用原预览。
- 飞书是可选 `ingest` 入口，仅该入口接受 `https://my.feishu.cn/wiki/<token>` 或 `/docx/<token>`。先 dryRun，按来源和 block ID 幂等录入，保存来源证据、提示词和视频引用，远程视频不落盘。相同库/标题/完整提示词/文件名/视频摘要才聚合卡片；无摘要时按视频引用判断。
- 来源匿名可读与视频匿名可播放须分别验证。运行时使用全新访客浏览器上下文取得飞书匿名授权，不使用用户档案或登录凭据。仅内存短期缓存匿名请求头，禁止记录 Cookie；公开权限变化时返回明确错误，不绕过登录。
- 专用 `/STASS/api/v1/ai-assets/media/{id}` 流式路由在现有工作台会话边界内服务本机视频或转发飞书视频，支持 Range、206 和 `download=1` 附件下载。飞书代理仅访问固定 HTTPS 视频域，禁止重定向，检查 MIME/大小，断开或异常时关闭上游。
- 预览、复制和资产录入不授权运行提示词、付费生成或发布。Motion 下载与执行仍遵守 Motion 子技能原边界；剪映库无来源时真实为空。收集到的提示词、源响应和媒体不得提交 Git。
- 验收包括本机空 Topic、分块续传和摘要失败、视频播放/拖动/下载、复制原文、飞书重复录入与多来源去重、导航回归和窄屏。飞书导入不产生本地媒体文件。保留原表格和 Motion 数据。

- 官方红白模目录从 skillto.ai 服务端读取，内嵌 www.skillto.ai/red-white/embed/topics/ 专用页面；本机来源分组与离线浏览继续保留。首发十一月 10 条免费，九月去重后 12 条、人民币 9 元。浏览器只将公开挑战 ID 带往顶层，飞书链接由线上页面在用户权益验证后交付。

- 官方专题按 API 返回顺序展示并默认选中云端指定免费项。官方专题和本机分组使用独立选择键，旧链接按已知映射解析，刷新及前进后退均恢复当前分组。生产嵌入限已登记的 `http://127.0.0.1:8080`，其他工作台地址显示官方独立页入口。
