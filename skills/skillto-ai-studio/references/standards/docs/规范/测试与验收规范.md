# 测试与验收规范

适用触发：测试、回归、验收。路径提示：`tests/**; apps/stass/**/test*`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 功能矩阵逐项验收，覆盖正常操作、失败和权限。全量核对数据关系、未知字段、历史、媒体哈希和引用；按格式及模块验证解码、播放、拖动、Range、音轨、倍速和下载。

- 验证网页/MCP双向回读、刷新重启、短链冲突/删除、视图恢复。用独立客户端、非回环监听及无服务端磁盘权限的自动化用例验证跨机连接。开发阶段缺少第二台机器时可先做隔离回归，正式发布满足下列实机门槛。

- 故障覆盖断网、冲突、无权限、磁盘不足、迁移中断、媒体缺失、任务未完成、端口占用及回退。

- 运行仓库检查和相关业务测试。收费生成仍需原授权；模拟不能冒充真实生成。任何未完成的跨机或依赖验收明确标为未完成，不将骨架或示例数据当作交付。

## 平台发行门槛

- Windows x64 用干净环境和另一台 Windows 实机，从公开 README 的一条 Prompt 安装待发布资产。覆盖自动打开、执行拦截后双击安装器、窗口拦截后使用稳定入口、自定义盘符与中文路径、同版本重试、旧版升级及中断恢复。核对实际打开的 EXE、网页、已安装 Skills 和清单一致，验证重启持久化及 Codex MCP 实际授权调用。Claude Code 的安装、发现和调用按宿主单独记录。
- 业务先验收空实例，安装后直接打开报表得到空状态，无需先写表格数据。以损坏和缺失的既有目录验证诊断，确认首次初始化不会覆盖已有数据。验证「AI资产」顶栏和旧 Motion 深链、文档页空状态及显式添加的链接仅在配置的实例可见。
- 检查发布标签、签名状态、清单、构建范围与实际安装资产。源码、可达历史和解包后的最终资产须通过个人数据与凭据检查。验收记录绑定平台、架构、版本、完整提交和清单摘要，并列出未通过或未实测项目。通过本机安装验证后可发布标明验收缺口的预发行，完整跨机验收用于正式版本。
- macOS 首期验收 Skills 安装与工作台支持状态提示。macOS 工作台上线前在干净目标机单独验证安装、启动、升级、恢复和宿主调用。平台状态须与 README 及发行说明一致。
