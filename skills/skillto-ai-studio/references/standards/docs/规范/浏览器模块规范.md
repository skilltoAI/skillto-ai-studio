# 浏览器模块规范

适用触发：浏览器用户、档案、会话。路径提示：`apps/stass/**/browser*`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 保留用户 CRUD、稳定 ID、独立 Chrome 档案、启动/关闭和删除恢复、浏览器 MCP。仅限服务所在机器的本机授权访问；局域网业务权限不意味着浏览器控制权限。档案仅同机同用户离线迁移，Cookie 不经局域网分发，不承诺跨机器保留登录。
- `/STASS/browser-users` 的每个用户提供抖音、小红书、视频号创作者中心、TikTok、X、Instagram 和 B站的单色 Logo 入口。点击时按稳定用户 ID 启动或复用对应的 Chrome 档案，再在该档案中新开标签页。图标随程序打包，支持键盘和窄屏。
