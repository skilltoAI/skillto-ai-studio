# 洗稿模块规范

适用触发：洗稿、稿件、配音、分析、分镜。路径提示：`skills/skillto-ai-studio-rewrite/**; apps/stass/**/rewrite*`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 保留 V0 只读、正文版本/Prompt、双版本多行编辑、换行空行、逐行标注、历史和修订冲突保护。五步导航为文案版本、原文亮点、原视效亮点、前12秒分镜、motion分镜表。

- 稿件分析和关键帧分析独立于配音正文。前12秒分镜保留各版本、人工意见及图片；motion分镜表保留表格版本关联和复制隔离。隐藏旧 fullStoryboard 入口但不清空历史。

- 切换前保存，失败保留草稿；不得仅替换修订号强行覆盖。旧表单不得擦除分析。

- 配音保留旧单文件与分段 WAV：按自然句边界每段最多200字符，保留正文措辞、版本关联、源文本哈希、播放器和下载。正文变化使配音失效；生成服务授权边界不变。
