# 表格模块规范

适用触发：表格、字段、筛选、标签、评分。路径提示：`skills/skillto-ai-studio-table/**`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 保留知识库/项目/表格三级 CRUD、稳定 ID、非空删除确认、九种字段类型和未知导入字段。保留行/表历史、删除快照、导入导出及血缘字段。

- 类型化筛选按 AND 组合；数字边界含端点，null 不当作0；日期错误提示，隐藏列仍可筛选。列偏好按表隔离。

- 标签 CRUD、多选、新建、改名保持关联，移除一个标签不影响其他字段。评分理由、标签、候选图人工选择相互独立；替换图片清除其旧选择。

- 保留视频单元格/悬停/全屏与触屏预览、short_video_info、图片预览。新表仅提供 schema 和记录即可使用控件；网页和 MCP 双向回读。

- 保留已有账号基准规则；表级 dataLineage 的 sources/methods/rules/destinations 及历史不得漏迁。

- 字段排序通过字段名排列保存到表定义，包含全部已定义字段，校验原顺序并保留字段定义、字段值、独立显示偏好及原历史。标签、评分和编辑属于固定操作列。
- 可编辑文本字段「人工处理备注」支持单元格内多行编辑与显式保存。请求只更新该字段，并校验打开时的值。保存失败保留输入，避免用旧页面覆盖已有内容。
