# 文档模块规范

适用触发：文档、飞书、知识库链接。路径提示：`apps/stass/**/documents*`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 文档页展示用户在当前实例显式配置的飞书文档及知识库链接。个人链接、标题、租户标识和说明仅存用户配置或业务数据。首次启动展示可配置的空状态；升级和迁移保留原实例已有的用户配置及关联。
- 程序和 Skills 的分发资源均禁止硬编码维护者个人引用。公开内容仅可使用经再分发审查的公共资源。界面只展示当前实例授权可见的内容；外部文档访问仍由飞书授权，文档页无需自动抓取或复制内容。
- 公开发行前按允许清单从干净提交构建，检查公开源码、目标引用可达历史和最终包内容，包括两套导航资源及生成后的前端。发现个人引用时阻止发行并分别核查链接分发与资源访问范围。记录受影响的提交和包，审查飞书分享权限，将修正版告知已知接收者。
