# 启动器与部署规范

适用触发：EXE、构建、启动、停止、部署。路径提示：`apps/stass/**/windows/**; apps/stass/**/build*`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 保留 Go 启动器和任务栏控制窗口：启动、停止、打开工作台、重复启动激活、健康复用、最小化继续、关闭窗口优雅停止。只停止自己管理且身份匹配的进程。

- 独立程序包与技能安装分开，程序不依赖 Codex/Claude 技能路径。配置注入数据目录、依赖和监听地址，不硬编码维护者环境。

- 保留 Metabase、PostgreSQL、FFmpeg、生成引擎等真实依赖并显示缺失状态。跨机嵌入不能指向访问者的127.0.0.1。EXE和机器配置不提交。

- Windows 启动器必须通过 `apps/stass/build_launcher.ps1` 构建：生成品牌图标资源、使用 `-H=windowsgui`，并检查产物的 GUI 子系统和图标。普通 `go build` 产物不能作为用户入口交付。

- EXE 文件名为 `Skillto.ai Studio.exe`，中文窗口和界面名称为 `SKillto.ai 个人工作台`，保留 Skillto.ai 品牌图标。

## README 驱动的 Windows 完整安装门槛

- 根 README.md 是唯一安装总入口，链接仓库内分步文档。分别提供程序加技能、仅客户端连接已有 STASS 两种路径，以及 Codex 和 Claude Code 的配置与验证；安装器不能把技能文件复制成功等同业务就绪。
- 明确所需 Windows 架构、Python/Go/Node 等实际依赖版本、下载来源、安装命令、检查命令、必需/可选外部服务及各自授权；构建依赖与用户运行依赖分开。依赖锁与实际产物一致。
- 从明确的版本或任务分支获取源码；程序须提供可复现构建或带版本和摘要的安装包，覆盖 EXE、服务、前端、静态资源、MCP 客户端和必要规范。不得以维护者 runtime 内的 EXE 链接替代分发。
- 程序目录、运行数据目录与技能目录隔离；路径从配置/安装位置解析，支持含空格及中文路径。安装不得依赖开发者用户目录、相邻仓库或临时服务脚本。
- 明示数据目录初始化、端口与监听配置、防火墙说明、令牌生成与保护、实例身份核验、配对和宿主 MCP 注册。不能复制维护者凭据或覆盖用户已有宿主配置；浏览器控制仍只限本机。
- 提供升级前备份、重复安装处理、回退及保留数据的卸载步骤；旧数据迁移须使用迁移规范的预检和一致性验证，不能把全新安装与生产迁移混为一谈。
- 安装验收覆盖启动、健康、九入口、MCP 工具发现、授权 CRUD、资源上传/读取、重启持久化、日志和停止；Codex/Claude 分别记录。收费与外部服务遵循各技能边界，缺失时明确未验证，不伪报通过。
- 发布前在不继承维护者路径/数据的干净 Windows 环境按 README 演练。当前没有第二台机器时可用隔离目录与自动化验证，但必须区分文件安装、协议测试、宿主实测和整套业务验收。缺口列于 README 可到达的审计表，并阻止“完整安装已通过”的声明。

## 同用户共享实例

- 默认根目录 `%LOCALAPPDATA%/Skillto.ai/Studio`；versions、config、data、backups、logs、staging 分离。自定义数据根只允许首次初始化，变更须显式迁移。
- 初始化和管理操作通过 Windows SID 加安装根标识的命名互斥锁串行化；服务持有独立生命周期锁。已有非空数据不得当作全新安装目录使用。
- 启动必须核验服务标识、实例 ID 和本次启动标识，不用 Python 包装器 PID 代替实际服务身份。端口归属不符则拒绝接管；停止只向本实例受管事件发送请求，禁止按端口或进程名批量杀进程。
- 关闭宿主不能停止共享服务。显式停止等待优雅退出，超时报告未完成，不强杀。生产升级还必须实现后台任务排空、备份及数据恢复门槛。
- 当前 runtime_state、runtime_control、supervisor 已完成隔离开发服务验收；生产安装、任务排空和统一升级仍未完成，不得据此部署替代旧工作台。

- 个人工作台允许升级时停服：先正常停止并确认进程退出，再切换程序和启动验收，不要求无停机升级。停服不授权丢弃业务数据或强制取消未完成生成任务；停止失败必须中止切换。

- EXE只读取用户共享根config/installation.json，通过其中选定程序的runtime_control管理服务。不得回退8880、已安装技能目录或旧HTTP身份。网页配对码由本机管理员接口获取，只在界面对话框展示，不写日志或URL。
