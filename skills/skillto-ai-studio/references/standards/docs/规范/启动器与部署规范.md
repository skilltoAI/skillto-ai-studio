# 启动器与部署规范

适用触发：EXE、构建、启动、停止、部署。路径提示：`apps/stass/**/windows/**; apps/stass/**/build*`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 保留 Go 启动器和任务栏控制窗口：启动、停止、打开工作台、重复启动激活、健康复用、最小化继续、关闭窗口优雅停止。只停止自己管理且身份匹配的进程。

- 程序与技能使用独立安装目录，完整安装由同一个入口编排。程序不依赖 Codex/Claude 技能路径。配置注入数据目录、依赖和监听地址。

- 保留 Metabase、PostgreSQL、FFmpeg、生成引擎等真实依赖并显示缺失状态。跨机嵌入不能指向访问者的127.0.0.1。EXE和机器配置不提交。

- Windows 启动器必须通过 `apps/stass/build_launcher.ps1` 构建：生成品牌图标资源、使用 `-H=windowsgui`，并检查产物的 GUI 子系统和图标。普通 `go build` 产物不能作为用户入口交付。

- EXE 文件名为 `Skillto.ai Studio.exe`，中文窗口和界面名称为 `SKillto.ai 个人工作台`，保留 Skillto.ai 品牌图标。

## README 安装入口与平台支持

- 公开源码、Claude Code marketplace 与发布资产入口统一指向 [项目 GitHub 仓库](https://github.com/skilltoAI/skillto-ai-studio)。根 README 提供可复制的一条 Prompt，通过仓库官方指引选择系统、架构和正式 Release，完整安装、尝试打开并回报结果；同时保留仅安装 Skills 或显式连接已有 STASS 的入口。

> 请从 https://github.com/skilltoAI/skillto-ai-studio 安装并打开 Skillto.ai Studio 工作台及 Codex Skills。按官方 README 使用适配本机的正式 Release，完成后回报版本、启动入口绝对路径和本机地址。

- Windows x64 首发提供单个已编译的 `Setup.exe`。安装端确定具体发行标签，校验官方发行记录中的 SHA-256。发行资产有代码签名时同时校验发布者签名。未签名可发行，须在发行说明标明签名状态及可能出现的 Windows 拦截。宿主拦截自动执行时，返回已校验安装器的绝对路径和实际原因。缺少适配资产时报告平台支持状态及可用的 Skills 路径。
- macOS 首期提供已验收的 Skills 安装路径。工作台待平台专属安装包、用户级运行管理和启动入口通过同等验收后开放。README 与 Release 按平台和架构列出可用能力、依赖和验收状态。Windows 的结果仅适用于 Windows。
- 明确所需 Windows 架构、Python/Go/Node 等实际依赖版本、下载来源、安装命令、检查命令、必需/可选外部服务及各自授权；构建依赖与用户运行依赖分开。依赖锁与实际产物一致。
- 维护端从固定提交构建，覆盖 EXE、服务、前端、静态资源、运行依赖、MCP 客户端、匹配 Skills 和必要规范。正式交付须来自可信发行记录列出的资产。
- 程序目录、运行数据目录与技能目录隔离；路径从配置/安装位置解析，支持含空格及中文路径。安装不得依赖开发者用户目录、相邻仓库或临时服务脚本。
- 安装器注册或复用实例，初始化空数据，安装同版本匹配的 Skills，检查用户已授权的 MCP 配置，启动并核验服务身份，再尝试打开窗口。说明监听、配对和宿主支持条件，保留用户已有宿主配置。浏览器控制仍只限本机。
- 通过开始菜单提供稳定的启动入口，由共享管理器解析实例配置，覆盖默认根和自定义盘符。窗口打开受限时返回该入口的绝对路径，并给出可执行的启动命令及自定义根所需的配置参数。原始版本目录中的 EXE 路径也应明确回报。
- 安装结果分别报告程序、Skills、MCP 和窗口状态，附发行版本、提交、清单摘要、启动入口及 EXE 绝对路径和本机地址。失败时标明阶段和恢复动作，保留既有实例和数据。目录移动失败应报告具体路径及系统错误，改装其他目录需明确选择并绑定正确实例。
- 提供升级前备份、重复安装处理、回退及保留数据的卸载步骤；旧数据迁移须使用迁移规范的预检和一致性验证，不能把全新安装与生产迁移混为一谈。
- 安装验收覆盖启动、健康、九入口、MCP 工具发现、授权 CRUD、资源上传/读取、重启持久化、日志和停止；Codex/Claude 分别记录。收费与外部服务遵循各技能边界，缺失时明确未验证，不伪报通过。
- 发布前执行[测试与验收规范](测试与验收规范.md)的跨机发行门槛。隔离目录与自动化可用于候选验证，验收记录分别列出文件安装、协议测试、宿主实测和整套业务结果。未满足的项目列于 README 可到达的审计表。

## 同用户共享实例

- 默认根目录 `%LOCALAPPDATA%/Skillto.ai/Studio`；versions、config、data、backups、logs、staging 分离。自定义数据根只允许首次初始化，变更须显式迁移。
- 初始化和管理操作通过 Windows SID 加安装根标识的命名互斥锁串行化；服务持有独立生命周期锁。已有非空数据不得当作全新安装目录使用。
- 启动必须核验服务标识、实例 ID 和本次启动标识，不用 Python 包装器 PID 代替实际服务身份。端口归属不符则拒绝接管；停止只向本实例受管事件发送请求，禁止按端口或进程名批量杀进程。
- 关闭宿主不能停止共享服务。显式停止等待优雅退出，超时报告未完成，不强杀。生产升级还必须实现后台任务排空、备份及数据恢复门槛。
- 当前 runtime_state、runtime_control、supervisor 已完成隔离开发服务验收；生产安装、任务排空和统一升级仍未完成，不得据此部署替代旧工作台。

- 开发变更需要重启或重新安装本机 STASS 服务或引导程序时，执行者应在本次任务内完成操作，无需另行请求用户授权。先检查并等待在途任务完成，使用共享管理器正常停止。重新安装按发行清单校验和版本切换流程执行，保留业务数据及配置。启动后核验服务健康、实际运行版本及受影响功能。停止失败必须中止切换。

- EXE 读取稳定启动入口绑定的共享根 `config/installation.json`，通过选定程序的 `runtime_control` 管理服务。直接调用版本 EXE 时支持显式配置参数。找不到配置时提示使用该实例的稳定入口或正确配置参数。不得回退 8880、已安装技能目录或旧 HTTP 身份。网页配对码由本机管理员接口获取，只在界面对话框展示，不写日志或 URL。

- 离线候选包从已提交快照构建，包含独立 Python 运行时、锁定的二进制依赖、EXE、技能和规范。安装前从可信交付渠道取得清单 SHA-256，按清单校验完整包，并对暂存副本再校验。相同包重复安装必须复用原实例和数据。

- 安装目录中的 Python 入口禁止写入字节码缓存。受管子进程显式使用 `-B`，MCP 客户端和桥接在导入前禁写缓存，以兼容未传 `-B` 的宿主。将离线解释器用于其他诊断命令时使用 `-B`。安装验收运行一次未传 `-B` 的桥接，再检查发行目录和完整清单。

- Go 窗口通过 Wails 和 WebView2 装载嵌入 EXE 的静态启动器界面。无界面诊断不加载 WebView2。离线候选包随清单校验完整的 WebView2 Evergreen x64 安装程序，仅在运行时缺失时安装。

- 3D 录屏使用独立品牌 Beam 组件。随发行包锁定上游源码和依赖，保存对应源码与许可证。Beam 项目与设置存放于独立的用户目录，关闭工作台或更新包不得强制终止录制或导出。

## 按工作选择

首次分类安装只询问一次，可直接接受五类工作名称或编号。分类、依赖、文案及可见入口从程序随附的 work_catalog.json 读取。偏好按用户保存，检测按宿主或组件实际所在实例进行。隐藏入口仅影响展示，原有链接、权限与数据继续可用。启动器在服务停止时仍可通过发行包的本地 Python 保存选择、检查技能文件并复制提示词。Web 管理入口限本机，沿用原服务的同源与访问控制。WorkBody 仅交接提示词；Chrome 扩展启用情况需在浏览器核对。
