# 界面与交互规范

适用触发：UI、导航、品牌、组件、样式、交互。路径提示：`apps/stass/**/assets/**; skills/**/assets/**`。多个命中必须累加读取。

状态：STASS 迁移目标约束，不代表对应功能已经实现或验收。

- 保留 Skillto.ai 个人工作台完整 Logo、白底、近白侧栏、灰黑文字、顶部九模块导航（不设单独「首页」入口）、三级内容关系及原有媒体颜色。复用公共样式与组件，不借重构删除功能或为单表定制页面。

- 支持键盘、窄屏和200%缩放；加载、空、失败、无权限和保存状态真实区分。切换页面清理播放、事件、轮询和计时器。

- 字段控件由 schema 驱动；显示字段偏好不修改业务数据。待保存内容先保存，失败留草稿并阻止切换。保留原有公共事件契约，短 URL 替换旧查询参数不应改变业务行为。

- 当真实连接对端与 Host 都是回环地址时，本机浏览器直接进入工作台。非回环网页使用一次性配对码经 POST 建立 HttpOnly、SameSite=Strict 会话。浏览器写请求必须验证同源，MCP 及管理员凭据仍单独校验。不得依赖转发头判定本机访问。
- 原生页面经程序内适配层访问共享业务模块，页面及接口请求统一带STASS前缀；资产补迁必须记录来源摘要。实际浏览器导航测试不能代替各模块全功能验收。

- 洗稿的 Motion 分镜表允许同源嵌入，其他网页页面继续禁止被嵌入。嵌入失败显示可读提示，编辑中或保存失败继续阻止离开。Metabase SDK 从配置的报表来源加载，不能给外部服务地址加 STASS 前缀。

- 洗稿页以稿件标题、圆点连线步骤条、版本工具栏和正文为序。步骤条保持键盘标签导航，版本按钮在空间不足时可横向滚动。空状态通知不占行，窄屏选定稿件后折叠目录，可用目录按钮重新展开。

- 工作台公共主题集中维护颜色、字体、圆角和浮层阴影。顶部导航高 56px，当前模块用底部黑线标识；桌面目录宽 248px，页面边距 28px，窄屏缩为 16px。表格先显示知识库／项目路径与表名，再显示已有概览、筛选、来源与数据。已应用的字段筛选可逐项清除。未经单独确认，不从静态原型引入演示指标、全局搜索或批量操作。

- 顶部「Motion 模版」改为「AI资产」，子导航提供 Motion 模版、AI红白模库、剪映AI模版库。红白模卡片直接展示可播放视频、完整可滚动提示词及复制/下载图标；遵循 [AI资产模块规范](AI资产模块规范.md)。
