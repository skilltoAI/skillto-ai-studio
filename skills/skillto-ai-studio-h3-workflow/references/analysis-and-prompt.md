# 原片证据、道具取舍与 H3 提示词

对每个 `[n.00,min(n+1.00,片尾))` 写原片观察：scene／硬切、机位和运镜、每个在场角色的画面位置、动作、表情与视线。只可见的事实写“观察”；情绪、观看钩子和潜在完播／互动作用写“推测”，注明证据帧时间戳。不要从标题、封面、音乐或整片流量数字推断某个细节的效果。

听原片音轨并逐段对照待替换角色的嘴部。若能看到角色随歌声或人声同步张合，记录角色 ID、时间段和证据帧，判定该角色需要对口型；纯背景音乐、嘴部不清、没有同步张合或无法判断时，不加对口型要求。不要把其他角色的口型要求套给所有新角色。

为每件显著服饰／道具建一行，字段为：`原角色ID｜物品｜出现时段及证据帧｜可见用途｜决策(保留/去掉/转译)｜对新角色的功能要求｜可能的观看作用(假设)｜置信度与风险`。保留支撑角色辨识、动作因果、反差或结尾回应的功能；可去掉无关装饰、遮挡新身份的物品。不同物种或物体形态时转译功能而非强套原服装。真实结果仍需检查 H3 是否保留，文本要求不是视觉保证。

另外逐段核对道具和环境的**显著状态变化**：道具是否出现／消失、点亮／熄灭、明显变色、转手或改变关键用途；场景是否硬切至另一地点，主光色、昼夜、天气或布景是否明显改变。每项写 `时间段与相邻证据帧｜变化前→变化后｜影响的角色／动作｜是否写入 H3`。仅在画面可核实且变化影响动作、角色映射或观看重点时写入 H3；镜头内的普通移动、暂时遮挡、压缩噪声和轻微亮度波动不算。没有明显、显著变化时，H3 提示词不出现变化描述，也不写“无变化”占位句。

定妆图片节点的提示词由 `skillto-ai-studio-character-card` 的 [直接引用合同](../../skillto-ai-studio-character-card/references/prompt-contract.md) 编写，不在本技能维护第二份模板。把每条实际连线的函数输入照片写成【新角色X（直接引用）】，把必要的原片关键帧写成【原视频待替换角色X（直接引用）】；明确移植的服饰道具和最终图只可出现新角色。缺少必留物品时不连关键帧，也不写第二图引用。定妆图比例、分辨率、参考图上限和提示词长度从图片 FMS 节点选项读取；输出图在实际运行前仍是待生成节点。

H3 节点提示词按以下逻辑组织，实际引用令牌和长度以服务端节点选项为准。`{{mixed_1}}` 等图片引用只指向定妆节点的输出；原视频引用须按图片数量从实际连线计算，不能固定假设总是 `{{mixed_2}}`：

```text
使用 <原视频引用> 的完整画面作为动作、场景、机位和镜头时序参考。只替换下列明确目标；未列出的角色、场景和无关物体保持原有关系。
角色1：原片中 <稳定画面位置／遮挡／独特动作> 的主体，由 <定妆图1引用> 的新角色身份替换。保留 <必需服饰或道具的功能、动作、情绪节奏>；去掉 <确认无助于叙事且遮挡新身份的装饰>。
角色2／3：仅在有对应输入和定妆节点时逐条加入，分别使用其定妆输出引用。
<仅当有证据时：在第XX秒，<道具或环境>由<前状态>变为<后状态>；<各新角色应对应的道具／光色／位置>。可按实际显著变化逐条加入；没有则整段省略。>
所生成的视频必须严格采用原视频<原视频引用>的音频。
<仅对已证实需要对口型的新角色，逐个加入简短对口型句。>
按已核实的硬切和动作顺序保持角色对应关系，不因换位而换错对象。不要额外生成镜头、品牌或剧情。原片不可判的细节保持不确定。
生成视频中只能出现【新角色1<定妆图1引用>】、【新角色2<定妆图2引用>】……<以及明确要保留的未替换角色，如有>；不得出现原视频<原视频引用>中的【原角色1：稳定位置／独特动作】、【原角色2：稳定位置／独特动作】……。
```

仅对事先确认需要对口型的角色，在音频句后逐个加入一句：`所生成的视频中的【新角色X<定妆图X引用>】必须对口型。` 没有证据时不加。模板中的尖括号说明是写作指引，不得原样进入最终提示词；没有显著道具／环境变化时整行省略。

**末句是强制约束**：按实际 1–3 路定妆图逐一写出“只能出现【新角色X{{mixed_N}}】”，并按同一映射逐一写出“不得出现原视频{{mixed_M}}中的【原角色X：可辨位置或动作】”。原角色描述只用于排除其身份，不把原角色姓名、脸或外貌带入新角色身份。若还有经核实必须保留的未替换角色，明确列入允许名单；若全部原角色都被替换，允许名单只列新角色。其他要求，包括音频和口型，均放在末句之前。不能用“不要留下原角色”等泛句代替，也不能漏掉一个待替换目标。

新角色的卡 ID、名称、物种、颜色或其他示例外貌不得写进 H3 节点提示词；只描述原片待替换目标的定位、定妆输出引用和必需的动作／道具功能。`<原视频引用>` 与 `<定妆图X引用>` 均按保存后的真实连线编号替换，不把占位符原样交给模型；无明确口型证据时不添加口型句。长篇逐秒证据保留在本地文档；H3 提示词只放模型合同允许且有助映射的内容。保存后回读，核对末句处于最后、每个定妆图引用与原角色排除项一一对应、可保留角色名单有证据、显著变化都有时间和相邻帧依据。若提示词长度不足以容纳末句和关键映射，或模型不能消费所连接的媒体，停止预检，不默默删掉角色或关键动作。成片后按实际视觉结果及音轨验收；提示词中的音频要求不是模型已原样复制音轨的保证。
