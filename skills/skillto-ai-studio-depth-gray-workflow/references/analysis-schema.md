# 结构化拆解字段

`source`：原视频 URL、视频 ID、文件绝对路径、采集时间、媒体时长/分辨率/帧率/音轨、采样策略与证据范围。

`characters[]`：稳定 ID、可见类型/物种、外形与饰物、首次/末次出现时间、可辨性限制。角色 ID 在同一视频的 scene 和逐秒表中一致。

`scenes[]`：编号、`start_s`、`end_s`、环境、在场角色、景别/机位/运镜、证据帧；`hard_cut_at_s` 只给经相邻帧核实的硬切。若全片单一连续 scene，仍填一条覆盖 `0.00～duration`，硬切列表为空。

`seconds[]`：每行覆盖 `[start_s,end_s)`，含 `scene_id`、`camera`、`framing`、`camera_motion`、`environment`、`evidence_frames`，并列出 `roles[]`：`id`、`screen_position`（左/中/右、前/中/后景，必要时估计百分比）、`body_pose_action`、`face_mouth`、`eyes_gaze`、`demeanor`、`emotion_inference`、`uncertainty`。同秒有多个角色时每个角色一条，不混写。不可判字段直写“不可判”。

时间统一保留两位小数展示，末段不足一秒时以真实片尾为 `end_s`。帧精度的切点按实际帧率换算；任何插值或模型推测均标明。音轨存在仅表明文件含音频，除非另行听取/转写，不描述具体声音。

## `原视频视频分镜细节.md` 固定骨架

下面是交付格式；`<...>` 为待填内容。一个视频一份，角色 ID 在全文件保持一致。每秒区间采用左闭右开，真实片尾不足 1 秒时写实际片尾。

```markdown
# 原视频视频分镜细节

## 1. 来源与核验
- URL / 视频 ID / 作者：<...>
- 本地原片：source.mp4；采集日期及方式：<...>
- 时长 / 宽×高 / 帧率 / 音视频轨：<...>
- 观察方法：完整观看；抽帧间隔 <...> 秒；额外核对的疑似切点 <...>；盲区 <...>

## 2. 原视频角色
| ID | 可见类型与外形 | 服饰/饰物 | 首次～末次出现 | 不确定点 |
| --- | --- | --- | --- | --- |
| R1 | <画面可见事实> | <...> | 0.00～<...> | <无/不可判> |

## 3. Scene 与硬切
| Scene ID | 起止秒（左闭右开） | 环境与在场角色 | 机位/景别/运镜 | 证据帧 |
| --- | --- | --- | --- | --- |
| S1 | 0.00～<...> | <...> | <...> | <时间戳> |

硬切：<“全片一个连续 scene；未见硬切”或逐条“第XX.XX秒硬切换；切前...；切后...；相邻原帧证据...”>。

## 4. 逐秒画面
### 0.00～1.00秒（Scene S1；证据帧：0.25s、0.75s）
- 可见事实：机位高度/角度 <...>；景别 <...>；运镜 <...>；环境与变化 <...>。
- R1：位置/景深 <...>；姿态动作 <...>；表情/口部 <...>；眼睛与视线 <...>；神态 <...>。
- R2（若在场）：同样逐字段填写；离屏直写离屏。
- 推测及依据：情绪 <...>，依据为 <可见动作/表情>；不确定点 <...>。

### 1.00～2.00秒
<重复相同字段，直到真实片尾；最后一段如 9.00～9.43秒>

## 5. 核对
- Scene 区间连续覆盖 0.00～片尾，无重叠；硬切均有相邻原帧证据。
- 逐秒区间连续覆盖 0.00～片尾，每个在场角色都有独立记录。
- 可见事实与推测分开；不可判/离屏明确标记；音轨内容仅在实际听辨后描述。
```

不得把模板中的示例时间戳、角色或媒体参数当成真实观察结果；交付时删除未替换的占位符。
